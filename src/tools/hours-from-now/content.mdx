## 几小时后是几点公式

本工具把「起始时刻 + N 小时」换算成目标钟点，核心按分钟累加：

```
总分钟 = 起始小时 × 60 + 起始分钟 + N × 60
当日时刻 = 总分钟 mod 1440（一天 1440 分钟）
跨天数 = floor(总分钟 ÷ 1440)
```

其中 N 可以是整数（3 小时）或小数（0.5 小时 = 30 分钟），负数表示往前推。

## 这个工具能做什么

它回答「从某个钟点起，再过 N 小时是几点」这类问题，常用于：

- 排班与交接：下班时间加工时得到收工钟点；
- 行程衔接：出发时间加车程得到到达钟点；
- 倒计时与提醒：现在加若干小时得到目标时刻；
- 任何需要「往后推几个小时」的场景。

结果以 24 小时制 HH:MM 呈现，并自动处理跨越午夜。

## 怎么使用本工具

1. 在「起始时间」填写或选择 24 小时制时刻（如 09:00）。
2. 在「加多少小时」输入数字，默认 3；负数表示往前推。
3. 结果区显示目标钟点；若跨越午夜会标注「跨到次日/前一天」。
4. 可一键复制结果。

## 计算详解

关键在于「对 1440 取模」：当总分钟超过一天，多余部分回到当日钟点，商即为跨过的天数。例如 23:00 加 3 小时：总分钟 = 23×60 + 0 + 180 = 1560；1560 mod 1440 = 120 → 02:00，floor(1560/1440)=1 → 跨到次日。小数小时按 0.5=30 分钟、0.25=15 分钟处理。

## 计算实例

**例 1：09:00 加 8 小时是几点？**

总分钟 = 540 + 480 = 1020；1020 mod 1440 = 1020 → 17:00，不跨天。即下午 5 点。

**例 2：23:30 加 2.5 小时？**

总分钟 = 1410 + 150 = 1560；mod 1440 = 120 → 02:00，跨到次日。

**例 3：14:00 减 5 小时？**

填 -5：总分钟 = 840 − 300 = 540 → 09:00，跨到前一天（负数商）。
