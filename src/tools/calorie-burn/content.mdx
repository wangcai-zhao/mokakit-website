## 为什么运动时总想知道「烧了多少卡」

减肥、健身的人最爱问「这组动作消耗多少」。热量消耗直接反映运动强度，也能帮你在「吃进多少、动掉多少」之间找平衡。可惜很多人凭感觉估，误差很大。用 MET 公式算，至少有个可比的参考。

本工具选运动类型、填体重和时长，按「MET × 体重 × 时长 ÷ 60」估算消耗。

## 公式长什么样

```
消耗(kcal) = MET × 体重(kg) × 时长(小时)
```

MET（代谢当量）是该项运动相对静息的代谢倍数。常见近似：

| 运动 | MET |
|---|---|
| 步行（5km/h） | 3.5 |
| 瑜伽 | 2.5 |
| 骑车（休闲） | 4.0 |
| 力量训练 | 5.0 |
| 慢跑（8km/h） | 8.0 |
| 游泳（自由泳） | 7.0 |
| 跳绳 | 11.0 |

## 为什么体重和强度都影响结果

- **体重越大**，同样运动消耗越多（要带动更重的身体）。
- **强度越高**，MET 越大，单位时间烧得越多。
- **时长越长**，总量自然累积。

所以想高效消耗，要么上强度，要么延长时间，本工具能帮你试不同组合。

## 本工具怎么用

三个输入：运动类型（内置 MET）、体重（kg）、时长（分钟）。结果给热量消耗和所用 MET 值，消耗高亮。

## 算出来能当「吃多少」的额度吗

只能粗略参考。食物热量、吸收率、个体代谢都波动大，「运动消耗 + 吃回来」极易超标。本工具帮你认识运动强度、做横向比较，别当成放纵的额度。
