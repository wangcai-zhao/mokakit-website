## 为什么需要 HTML 转 Markdown

把网页内容、邮件、富文本编辑器输出搬进笔记 / 文档 / README 时，往往拿到的是 HTML。直接贴进去既丑又带一堆 `<div>`、`<span>` 样式。转成 Markdown 才干净、好维护、跨平台通用。

本工具用启发式规则把 HTML 转成 Markdown：标题、段落、列表、链接、图片、引用、代码、表格都被尽量还原成对应的 Markdown 语法。

## 概念与公式

转换是「标签 → Markdown 语法」的映射（基于 DOM 解析，而非正则硬砍，能正确处理嵌套）：

- `h1–h6` → `#`~`######` 前缀；
- `p`/`br` → 段落与换行；
- `a` → `[文本](href)`；
- `img` → `![alt](src)`；
- `strong`/`b` → `**粗**`，`em`/`i` → `*斜*`；
- `ul`/`ol` → `- ` / `1. ` 列表；
- `blockquote` → `> ` 引用；
- `pre`/`code` → 代码块 / 行内代码；
- `table` → `|` 表格。

启发式意味着极端或自定义组件可能还原不完美，但常规内容（文章、文档）效果良好。

## 细分场景

- **笔记导入**：网页文章转 Markdown 进 Obsidian / 语雀。
- **文档生成**：把富文本编辑器输出存成 `.md`。
- **邮件归档**：HTML 邮件转纯文本 Markdown。

## 怎么用本工具

把 HTML 贴入左侧，右侧即时生成 Markdown，复制即用。可选「保留链接」「保留图片」等开关。复杂页面建议人工过一遍表格/嵌套列表。

## 常见场景与实例

**例：带链接的段落**
`<p>详见 <a href="https://a.com">文档</a></p>` → `详见 [文档](https://a.com)`。

**例：标题 + 列表**
`<h2>步骤</h2><ul><li>一</li><li>二</li></ul>` → `## 步骤` 加两行 `- ` 列表。
