## SKILL 生成原理

按 WorkBuddy 技能约定生成 SKILL.md：含 name / description / 触发词与标准工作流段落

description 是技能被检索命中的关键字段

## 这个工具能做什么

- 生成符合规范的 SKILL.md 骨架
- 填写触发词与工作流
- 本地生成，可下载

## 怎么使用（输入说明）

1. **填技能名与描述**：描述要写明「何时用、做什么」。
2. **填工作流**：列出步骤与注意事项。
3. **生成**：得到 SKILL.md 文本。

## description 字段有什么讲究

description 是智能体决定「是否调用该技能」的依据，应写明触发场景与能力边界，避免空泛；触发词也要贴近用户真实表述。

## 计算实例

例：一个「会议纪要」技能，description 写「用户给录音/文字要求整理会议纪要时调用」。

## 常见问题 FAQ

**Q：生成的 SKILL.md 放在哪里才能被 WorkBuddy 识别？**

A：用户级技能放到 ~/.workbuddy/skills/，项目级技能放到 \{项目\}/.workbuddy/skills/。每个技能一个目录，把生成的 SKILL.md 放进去即可，WorkBuddy 会自动发现。

**Q：description 字段有什么讲究？**

A：description 是技能被触发的关键，建议写清「这个技能做什么」以及「用户什么情况下该用它」，WorkBuddy 会据此判断要不要加载该技能。
