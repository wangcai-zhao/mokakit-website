## 为什么需要查询参数解析

URL 后面那一串 `?a=1&b=2&utm_source=wechat` 就是查询参数（query string）。前端联调、排查埋点、构造回调地址时，经常要把这串东西拆开看、改、再拼回去。手工改 `&` 和 `=` 容易漏编码、多符号。

本工具把查询字符串解析成清晰的键值对表格，也能反向把键值对拼成合法 URL——编码、去重、排序一步到位。

## 概念与公式

查询字符串是 `?` 之后、`#` 之前的 `key=value` 用 `&` 连接的部分。规则要点：

- 键值都要做百分号编码（URL encoding），空格变成 `%20` 或 `+`。
- 同名 key 可重复出现（如 `tag=a&tag=b`）。
- 数组常见写法 `arr=1&arr=2` 或 `arr[]=1`。

解析 = 按 `&` 切分，再按首个 `=` 拆 key/value 并解码；拼装 = 反向编码并用 `&` 连接。本工具两种方向都支持。

## 细分场景

- **前端联调**：确认后端收到的参数和你拼的是不是一致。
- **埋点排查**：看 `utm_*` 系列有没有漏、有没有被截断。
- **构造回调 / 跳转 URL**：安全拼接参数，避免手工拼接破坏格式。

## 怎么用本工具

把整条 URL 或纯查询串贴入，工具自动解析成表格（key、value、解码后值）；也可切到「构建」模式，逐行填键值对，下方实时生成编码后的查询串。支持一键复制结果。

## 常见场景与实例

**例：解析**
`?page=2&q=咖啡&sort=price` → 三行键值对，中文 `咖啡` 解码正常显示。

**例：拼装**
填 `redirect=https://a.com/x` → 自动编码成 `redirect=https%3A%2F%2Fa.com%2Fx`。
