## 进制转换原理

任意进制 N 转十进制：按位权展开 Σ(数字 × N^位序)

十进制转任意进制：反复除 N 取余数，倒序排列

整数用 BigInt 任意精度；小数按 IEEE 754 双精度（1 符号 + 11 指数 + 52 尾数）表示

## 这个工具能做什么

- 在 2/8/10/16/32/36 及 2-36 任意进制间互转
- 全进制一览：输入一次，同屏查看所有常用进制的结果
- 输出分组（每 4 位）与 0x / 0b 前缀开关
- IEEE 754 浮点说明：十进制小数转双精度十六进制，拆解符号位/指数/尾数
- 处理超出普通数字精度的大整数

## 怎么使用（输入说明）

1. **输入数值**：按源进制规则填写（二进制只含 0/1），支持下划线分组如 1_000_000。
2. **选择源/目标进制**：点预设按钮或直接输入 2-36；「交换进制」一键互换。
3. **看结果**：主结果区显示目标进制值；下方「全进制一览」给出 2/8/10/16/32/36 全部结果，均可一键复制。
4. **显示选项**：勾选「分组显示」长数字每 4 位加空格；勾选「0x/0b 前缀」给十六进制/二进制加标准前缀。
5. **浮点查询**：展开底部「IEEE 754」区，输入小数即得双精度十六进制表示。

## 为什么用 BigInt

JavaScript 普通数字有 2^53 精度上限，超过会失真；BigInt 可表示任意大整数，保证进制转换在密码学、哈希等场景下结果精确。小数部分不适用 BigInt，按 IEEE 754 双精度浮点表示，存在固有误差。

## 计算实例

例：输入 255（十进制）→ 二进制 11111111 / 八进制 377 / 十六进制 ff / 32 进制 7v / 36 进制 73。

例：3.14 的 IEEE 754 双精度十六进制为 0x400921FB54442D18；而 0.1 的表示 0x3FB999999999999A 比精确值略大，浮点累加即产生误差。

## 常见问题 FAQ

**Q：为什么用 BigInt 而不是普通数字？**

A：JavaScript 的普通数字（Number）是双精度浮点，超过 2^53 就会丢精度，很长的十六进制或二进制串会算错。本工具使用 BigInt 做任意精度整数运算，无论多长都能精确转换。

**Q：十六进制里的字母大小写有区别吗？**

A：没有。A 和 a 都表示十进制的 10，B 和 b 都表示 11，以此类推。本工具统一用小写字母输出，输入时大小写均可。

**Q：支持的进制范围是多少？**

A：支持 2 到 36 进制。超过 36 需要更多字符来表示数值，常规场景用不到，因此本工具未提供支持。

**Q：IEEE 754 折叠区是做什么的？**

A：输入十进制小数（如 3.14、0.1），即可得到它的双精度浮点（float64）十六进制表示，并拆解符号位、指数、尾数三段，能直观看到 0.1 为什么存不下、0.1+0.2 为什么不等于 0.3。
