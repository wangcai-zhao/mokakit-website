## Bing Webmaster Tools 数据驱动 SEO 诊断（MokaKit）

- 输入：旺财从 Bing 站长平台导出的 6 份 CSV（Country / Device / PageTraffic / Keyword / SearchPerformanceOverview / SEOAnalysisSummary），区间 2026-08-25 → 10-06（43 天）。
- 产出：
  - 分析脚本 `scripts/seo-bing-analysis.mjs`（可重复跑，换 CSV 复算；含 A–F 六组机会清单）
  - 方案文档 `outputs/seo-bing-optimization-plan.html`
- 核心结论（后续会话直接复用，不用重算）：
  - 总盘：36,648 展现 / 708 点击 / CTR 1.93%；138 页有展现、470 个词；前十页占 62% 展现。
  - **主因是排名不是文案**：主力页平均排名全在 5.1–9.8 死区，该区间自然 CTR 就 1–3%。
  - **铁证（最重要）**：标题首词是否等于查询词 → CTR 差 2.5 倍。数字时钟类（首词命中）pos7.25 / CTR 2.58%；在线时钟类 pos7.82 / CTR 1.05%；全屏大屏类 pos7.93 / CTR 0.98%。极端对照：模拟时钟 pos7.64 → CTR 22.73%，全屏时钟 pos8.18 → CTR 0.16%（1272 展现仅 2 点击）。
  - 时钟族 8,813 展现（占全站 24%）全砸在 `/tools/digital-clock/` 一页，四种意图混在一页 → 建议拆成 digital-clock / flip-clock / 新建全屏时钟页，标题分工不抢词。
  - **214 个 unit-convert 子页，198 个零展现**，仅 16 个有展现（582 展现 / 4 点击），标题仅 12 字符（"圈换算度 | 摩卡工具箱"），是 Bing「38 页标题过短」的主体，且稀释抓取预算。推荐 A 案：保留 20–30 个高频对补长标题，其余 noindex + 移出 sitemap。
  - 唯一跑通的词：token 计算器 688 展现 / 90 点击 / CTR 13.08% / pos 3.65，值得冲第 1（补 Claude/Gemini/DeepSeek/Qwen 编码 + token 价格换算）。
  - 5 个零点击大词：比例 706、时间间隔计算器 335、密度单位 272、工作日计算器在线 216、北京时间全屏显示数字 140（合计 1,669 展现 0 点击）。
  - 移动端 CTR 5.96%、pos 5.39 均优于桌面（1.84% / 7.07），但移动展现仅占 5.2% → 曝光不足非质量差。
  - Bing 高严重性「4 页未 IndexNow 提交」= 10-06 新增的 5 个工具（download-time-calculator / labor-income-tax / second-hand-house-tax / shipping-fee-calculator / vehicle-purchase-tax），重跑 `npm run indexnow` 即可。
- 收益测算：P0 完成 ≈ 850 点击 / 43 天，P0+P1 ≈ 1,100（CTR 1.93% → 3.0%）。
