## 为什么「最强模型」这个问题本身是错的

同一个模型，写代码能到 9 分，读图可能只有 4 分；中文口语很自然的模型，碰上严谨的合同条款又会漏掉互相引用的定义。所谓选型，本质是**先想清楚这类任务最看重什么，再去看哪个模型在那几项上不掉队**。

场景选模型助手把这件事做成了可计算的：18 类场景各自给能力维度分配权重，9 项硬性约束负责排除，最后用加权分给出匹配度排名，并把「为什么是它」「要接受什么代价」「谁被排除了、为什么」全部摊开给你看。全程在浏览器本地计算，需求描述不上传。

## 覆盖哪些场景

场景按五组归拢，不需要你先懂模型术语，照着业务说就行：

- **开发与工程**：写代码 / 调试、智能体与工作流、代码审查与重构、数据分析 / SQL
- **内容与营销**：文案与文章、短视频脚本口播、营销 / SEO / 投放、翻译与本地化
- **分析与专业**：深度研究与行业报告、长文摘要与会议纪要、合同与法律文书、数学与科研计算、教学答疑、图片 / 截图 / OCR
- **对话与知识**：客服与问答机器人、角色扮演与陪伴、知识库 / RAG 问答
- **批量与运营**：批量清洗、打标、抽取

每类场景背后是一组权重。例如「客服机器人」把中文 24%、速度 20%、成本 20% 放在最前面，因为一天几万轮对话里，慢和贵都是致命的；而「合同审阅」把推理 36%、长文 24% 顶上来，省钱在这里是次要的。

## 9 项约束怎么改变结果

约束分两种，页面上会明确标出代价：

| 约束 | 类型 | 实际作用 |
| --- | --- | --- |
| 预算敏感 | 加权 | 成本权重 +18%，并标出成本偏高的选项 |
| 准确率优先 | 加权 | 推理 +14%、成本 −8%，旗舰模型上浮 |
| 要快（实时交互） | 加权 | 速度 +15%，慢模型会被提示 |
| 海量调用 | 加权 | 成本 +12%、速度 +8%，适合万级日调用 |
| 必须能读图 | 硬过滤 | 视觉低于 7 分的模型直接出局 |
| 必须稳定出 JSON | 硬过滤 | 结构化输出低于 7 分出局，并加权 |
| 单次超长材料 | 硬过滤 | 上下文不足 300K 的模型出局 |
| 要私有化 / 数据不出内网 | 硬过滤 | 只留开放权重、可本地部署的模型 |
| 国内直连 / 开票合规 | 硬过滤 | 只留境内可直连的模型 |

硬过滤不是拍脑袋：每个被排除的模型都会写明原因，例如「图像理解 4/10，低于『必须能读图』门槛 7」。约束点之前也能看到它会排除几个模型，避免一勾就只剩两个选项。

## 怎么用（四步）

1. **说需求**：一句话写清「做什么 + 给谁用 + 有什么限制」，例如「给公司做个中文客服机器人，每天大概 2 万次对话，预算有限」。工具会本地匹配出场景与约束，并显示命中的词和置信度。
2. **确认或改选场景**：识别错了就直接点上面的场景按钮；18 个场景按组排好，也提供了四个常用组合一键进入。
3. **加约束（可选）**：预算、私有化、读图、长上下文等按需勾选；顺手填一下日调用量和 token 数，月成本会一起算出来。
4. **看推荐并对比**：首选卡给出匹配度、三条加分项、代价提示和月成本；下方完整榜单可以逐行拆解评分，勾选 2-3 个模型生成对照表与雷达图，最后可一键复制结论。

## 结果怎么读才不会被误导

- **匹配度是相对分，不是绝对分**。它只回答「在你选的这套权重下，谁更合适」，满分 100 也不代表模型有 100 分能力。
- **先看「要接受的代价」**。如果一个模型三项加分很漂亮，但「视觉 4/10」正好是你要用的能力，那它就不该是你的首选。
- **备选要换供应商**。工具默认给出的备选一定来自另一家厂商，避免接口、限流、合规上的单点依赖。
- **省钱替代要卡住分差**。只有匹配度差距在 8 分以内、单价明显更低的模型才会被推为「省钱替代」，不是无脑推最便宜的。
- **成本按你的用量算**。月成本 = 日调用次数 × 30 ×（输入 token × 输入价 + 输出 token × 输出价），输出价没公开的模型不会瞎估。

## 三条实战建议

第一，**先用小模型分流，再用大模型兜底**。客服、分类、抽取这类高频任务，用便宜档处理 80% 的常规请求，把复杂工单转给旗舰模型，总成本通常能砍掉一半以上，体验几乎不掉。

第二，**别只看榜单第一名**。选型的真实收益往往来自「第二名便宜一半、分数只差 3 分」这种组合，工具里的省钱替代就是专门找这类机会的。

第三，**上线前一定压测**。拿 50-100 条你自己的真实样本，按「必须答对 / 可以容忍」两档打分，跑两轮再定。公开能力和你的业务分布之间，永远隔着一段只有数据能填的沟。

## 常见问题 FAQ

**Q：推荐依据是什么？准吗？**

A：把场景拆成权重（如「中文客服」里中文 24%、速度 20%、成本 20%），再用人工维护的能力评分加权算出匹配度。它是选型的起点和排除法，不是跑分；最终请用你自己的真实样本压测。

**Q：为什么第一名常常是便宜模型？**

A：因为便宜模型在中文、长上下文、成本三项上确实能打。若你更看重写作质感或严谨推理，勾选「准确率优先」或换到「合同审阅」这类场景，权重会自然把旗舰模型顶上来。

**Q：数据和价格从哪来？多久更新？**

A：能力评分为人工维护的口径，价格与「AI 价格比价」共用同一份快照。大模型调价与发版频繁，正式采购请以厂商官网公示价为准。

**Q：想私有化部署，还能用这个工具吗？**

A：勾选「要私有化 / 数据不出内网」，只会保留开放权重、可本地部署的模型，并列出被排除的闭源模型及原因。

**Q：支持多模型对比吗？**

A：支持。在榜单上勾选最多 3 个模型，会生成 11 项能力对照表、雷达图和部署方式差异；默认已带上首选、备选与省钱替代。

需要查具体单价与月成本明细，可以配合 [AI 价格比价](/tools/ai-price-compare/) 一起用；想知道一轮对话能吃多少 token，用 [上下文窗口计算器](/tools/context-window-calculator/)；确定模型后要写系统提示词，接着用 [系统提示词生成器](/tools/system-prompt-generator/)。
