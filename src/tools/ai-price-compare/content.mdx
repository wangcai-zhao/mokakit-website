## AI 模型价格对比原理

大模型 API 按 token 计费，输入与输出分开计价，单位通常是「每百万 token」

单次成本 = 输入 token 数 × 输入单价 + 输出 token 数 × 输出单价

月成本 = 单次成本 × 30 × 每日调用次数；人民币价按可调汇率折算，仅作直观对比

## 这个工具能做什么

- 对比主流大模型按量计费的输入/输出单价（每百万 token）
- 按场景估算单次与月度调用成本，横向比较性价比
- 模型级勾选：只对比你关心的几个模型，厂商按钮可整组开关
- 汇率可调并记忆在本机浏览器，¥ 列即时重算
- 视觉生成 Tab：即梦、可灵、Runway、Sora、Veo 等图片/视频工具价格

## 怎么使用（输入说明）

1. **调整汇率**：页面右上角改 USD→CNY 汇率（默认 7.2），所有 ¥ 列与月成本即时重算，刷新后保持。
2. **勾选模型**：厂商按钮整组开关，展开「模型级勾选」可精确到单个模型；支持全选/清空。
3. **估算成本**：填入输入/输出 token 数与每日调用次数，得到单次成本与月成本排名（输出价未公开的模型不参与估算）。
4. **看视觉价格**：切到「视觉生成价格」Tab 查看即梦、可灵等按张/按秒计费的产品。

## 常见问题 FAQ

**Q：价格是实时获取的吗？**

A：不是。价格为人工维护的参考快照（数据更新于 2026-10-24），大模型与视觉生成平台调价频繁，正式采购请以各厂商官网公示价为准。

**Q：货币怎么看？**

A：国际大模型官方以美元（USD）计费，本工具默认按 1 USD ≈ 7.2 CNY 折算出人民币参考价；汇率可在页面顶部自行调整并记忆在本机浏览器，仅作直观对比，实际以账单为准。

**Q：月成本是怎么算出来的？**

A：月成本 = 单次调用成本 × 30 天 × 每日调用次数。在「场景成本估算」区填入输入/输出 token 数和每日调用次数，即可横向对比各模型的月度开支，方便做预算。

**Q：为什么没有豆包/文心等的输出价？**

A：部分国产模型仅公开输入价或采用积分/会员制，输出价随档位浮动，为避免误导此处留空或标注「会员制」，建议以官方报价页核对。
