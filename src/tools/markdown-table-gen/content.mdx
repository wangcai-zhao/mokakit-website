## Markdown 表格生成是什么

Markdown 表格的麻烦在于手写对齐：每一列宽度要数着空格填。交给工具生成，源码和渲染结果都整齐。

## 这个工具能做什么

- CSV / 逗号分隔 / JSON 数组三种输入
- 左中右三种对齐方式
- 可选补齐空格让源码对齐
- 同时给出 HTML 版本与渲染预览

## 怎么使用（输入说明）

1. **选输入格式并粘贴数据**
2. **设表头与对齐方式**
3. **看渲染效果**
4. **复制 Markdown 或 HTML**

## 使用时的几个注意点

- 竖线会自动转义
- 复杂表格请用 HTML 版本
- JSON 输入会自动合并所有对象的键

## 实例

三行两列的 CSV，左对齐并补空格，生成整齐的 Markdown 表格源码。

## 常见问题 FAQ

**Q：单元格里有竖线怎么办？**

A：工具会自动转义成 \|，否则会撑破表格结构。这点手工写表格时最容易漏。

**Q：JSON 输入的键顺序怎么定？**

A：取所有对象里出现过的键的并集，按首次出现的顺序排列，缺失的字段留空。

**Q：Markdown 表格能做合并单元格吗？**

A：不能。Markdown 表格语法不支持合并单元格、换行和列宽控制，遇到复杂表格直接用工具给出的 HTML 版本。
