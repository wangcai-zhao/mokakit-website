## 一、项目检查

### 1.1 技术栈

| 层 | 选型 | 版本 |
|---|---|---|
| 框架 | Astro（静态输出，`trailingSlash: always` + `format: directory`） | 7.1.6 |

站点**无后端业务逻辑**，所有工具在浏览器本地计算；仅两个自建服务：MCP Server、匿名计数服务。

### 1.3 核心模块职责与调用关系

| 模块 | 职责 | 被谁调用 |
|---|---|---|
| `src/config/site.ts` | **唯一配置真源**：域名、备案号、统计/广告开关、计数接口、版本号（由 package.json 派生） | 全站布局、utils、页面 |
| `src/tools/registry.ts` | **工具自动发现**：`import.meta.glob` 收集全部 `meta.ts`；排序、分类、相关推荐、搜索索引 | 首页、工具索引、分类页、搜索、sitemap |
| `src/components/WidgetHost.astro` | **水合注册中心**，唯一手工接入点（Astro 要求静态 import，无法自动发现） | 工具页 |
| `src/layouts/` ×3 | Base（通用）/ Tool（工具页）/ ClockImmersive（全屏时钟，隐藏页脚但另配备案条） | 各页面 |
| `src/components/` ×14 | 头部、页脚、面包屑、工具卡、广告位、图标字典（141 个真实图标）、**CounterScript（两个布局共用的计数脚本）** | 布局与页面 |
| `src/utils/` | outbound（出站走 `/go/` 中转）、jsonld（结构化数据）、favicon、counter | 组件与页面 |
| `src/lib/` ×5 | 中国本土财金算法库（个税/社保/增值税/契税等/房贷），纯函数、零浏览器 API | **MCP Server 为主；前端工具多数未复用（见问题 2）** |
| `src/tools/_shared/` ×32 | 共享组件与工具函数，`copy` 被 116 处引用，`dev-io` 16 处，`linear-convert` 15 处 | 240 个工具 |
| `scripts/` | 构建后处理（雪碧图瘦身、sitemap）+ 四项校验（水合/图标/单位/更新日志）+ SEO 审计 | `npm run build` / `check:all` |
| `mcp/` | MCP Server：把工具能力暴露给 AI 助手，JSON-RPC 2.0 over HTTP，可选 Bearer | 外部 AI 客户端 |
| `deploy/` | nginx 配置、部署脚本、计数服务（systemd）、server-setup | 运维 |

**两条关键链路：**

1. **工具上线链路**：新建目录 → registry 自动发现 → **必须在 WidgetHost 手工注册水合** → 构建 → `check:widgets` 校验。
   漏掉注册环节**不会报错**，页面照常生成，只是点不动（2026-09-23 曾有 11 个工具中招）。
2. **金额计算链路**：`src/lib/` 纯函数应同时供前端与 MCP 使用。当前 MCP 用库，而 6 个前端工具各自内联了一份算法 —— 这是本次发现的架构隐患。

## 二、风险评估

分级：**P0** 崩溃/算错钱/安全漏洞　**P1** 功能或合规受损但不崩　**P2** 体验与冗余

### 2.1 已确认并修复（2 项）

| 级别 | 位置 | 问题 | 影响 |
|---|---|---|---|
| P1 | `src/pages/privacy.astro:8/11/46` | 隐私政策与实际配置不符：站点已开启百度统计与 AdSense（`site.ts` 中 `ads.enabled=true`、`adsenseClient`、`baiduId` 均已填），隐私页却仍声明「不加载第三方广告或统计埋点（上线初期默认关闭）」；且列举联网工具时遗漏了会请求 Open-Meteo 的天气查询 | 隐私声明与实际行为不一致，属合规风险 |
| P1 | `src/tools/deed-tax/Tool.tsx`（旧 19–26 行） | 契税面积分界线与税率在**组件与算法库各写一份**，MCP 用库、前端用组件。这正是 2026-09-23「按 90㎡ 老口径算错税」事故的根因，当时只补了数值，未消除双份结构 | 任一处再改漏另一处，前端与 MCP 就会算出不同税额 |

### 2.2 待你决策（5 项）

| 级别 | 位置 | 问题 | 影响范围 |

### 2.4 已验证健康（排除项，供你放心）

这几项是容易藏雷的地方，本轮逐一验证过，**未发现问题**：

- **水合完整性**：240/240 工具都已接入 WidgetHost（`npm run check:widgets`）
- **图标**：141 个真实图标，别名表为空，240 个工具图标全部可解析
- **更新日志**：240/240 工具已登记，无悬空 id
- **meta 全量静态校验**（240 个）：id 与目录名一致、category 合法、日期无未来值/无倒挂、description 长度全部落在 80–160、keywords ≥3、三件套齐全、related 无幽灵引用、Tool.tsx 均有默认导出 —— **零问题**
- **MDX 红线**：构建通过，且抽查确认告警均为误报（`<` 出现在行内代码或合法 Astro 组件内）
- **SEO**：审计 **0 问题**；sitemap 585 条 URL；noindex 页（`/go/`、`/search/`）未进 sitemap；lastmod 无未来日期
- **内链**：全站正文/meta/数据扫描，**零死链**
- **契税口径**：库、组件、页面文案、FAQ、博客指南均为 140㎡，一致
- **计数服务**：原子写（tmp+rename）、key 白名单正则、5 万 key 上限、8 KB body 限制、**不记录 IP/UA**、无访问日志 —— 与隐私承诺相符
- **MCP 鉴权**：POST/DELETE 有 Bearer 守卫，GET 返回 405，无绕过路径
- **出站跳转**：协议白名单限制为 http/https 且排除本站域名，站内链接不会被中转
