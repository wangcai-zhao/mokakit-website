## URL 解析原理

按 URL 标准结构拆分：protocol://host:port/path?query#fragment

查询串进一步按 & 与 = 拆成键值对

## 这个工具能做什么

- 把完整 URL 拆成协议、域名、端口、路径、参数、锚点
- 查看每个组成部分
- 本地解析，不上传

## 怎么使用（输入说明）

1. **输入 URL**：粘入完整链接。
2. **查看**：工具分字段展示各组成部分，query 参数展开为键值列表。

## 为什么解析参数有用

调试接口、分析跳转、提取回调参数时常需看清单个 query 的含义；本工具把 ?a=1&b=2 拆成可读表格，便于核对。

## 计算实例

例：https://x.com/p?a=1&b=2#top → 协议 https、主机 x.com、路径 /p、参数 a=1,b=2、锚点 top。

## 常见问题 FAQ

**Q：为什么提示 URL 无效？**

A：解析基于浏览器原生 URL 标准，网址必须带协议头。若只填了 example.com/path，工具会自动按 https:// 补全再试；仍失败通常是含非法字符或结构不完整。

**Q：参数值里的中文和 %XX 会自动还原吗？**

A：会。表格中展示的是解码后的可读值，中文、空格等百分号编码都会还原。若想拿到编码前的原始串，可用站内的 URL 编解码工具反向处理。

**Q：同名参数出现多次怎么显示？**

A：会按出现顺序逐条列出，不会互相覆盖，方便检查 tags=a&tags=b 这类数组式传参是否符合预期。

**Q：解析结果包含密码字段安全吗？**

A：解析在本地进行，不会上传；但 URL 中若直接嵌入账号密码（如 https://user:pass@host）属于明文风险，建议不要在任何地方这样传凭据。
