## 智能体命名生成器的原理

好名字降低记忆成本、也影响用户对「它干什么」的第一印象。命名生成器用「前缀 + 核心词 + 后缀」的词库组合，按你选的风格批量产出候选，再把筛选交给你，比空想要快得多。

## 这个工具能做什么

- 按风格批量产出候选名
- 支持科技 / 可爱 / 专业 / 极简
- 给出可注册性提示
- 一键复制心仪的名字

## 怎么使用（输入说明）

1. **填关键词**：你的智能体是做什么的。
2. **选风格**：点一种命名调性。
3. **生成**：得到一批候选名。
4. **挑选**：复制喜欢的去查重。

## 常见问题 FAQ

**Q：名字会重复吗？**

A：组合来自内置词库，可能与现有产品重名，正式使用前请自行检索商标 / 域名。

**Q：能指定语言吗？**

A：支持中英文混合风格，可在关键词里控制。

**Q：生成随机还是固定？**

A：每次点生成重新随机组合，多试几次挑到满意的。
