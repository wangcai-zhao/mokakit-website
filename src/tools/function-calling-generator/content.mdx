## 函数调用 Schema 生成器的原理

让大模型「调工具」的前提，是先告诉它有哪些工具、每个工具要什么参数。函数调用定义就是一段带类型的 JSON Schema。生成器把手工拼 JSON 的易错过程变成表单填写，并同时输出 OpenAI 与 Anthropic 两种格式，降低接入门槛。

## 这个工具能做什么

- 表单化添加参数并实时校验
- 同时输出 OpenAI / Anthropic 格式
- 自动补全 required 与类型
- 复制即用，减少手抖写错

## 怎么使用（输入说明）

1. **填工具名与用途**：给函数起名并说明它能做什么。
2. **加参数**：逐行添加参数名、类型、描述、是否必填。
3. **生成**：点生成得到两种格式的 JSON。
4. **复制接入**：复制进你的智能体代码。

## 常见问题 FAQ

**Q：支持哪些类型？**

A：覆盖 string / number / integer / boolean / array / object 等 JSON Schema 基础类型，足够描述绝大多数工具入参。

**Q：两种格式差别大吗？**

A：语义一致，仅字段命名略有不同（如 parameters 的位置），本工具已为你分别生成。

**Q：会校验必填吗？**

A：会。勾选必填的参数会自动进入 required 数组。
