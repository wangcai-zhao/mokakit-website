## 上下文窗口计算器的原理

上下文窗口是模型单次能「看到」的 token 上限。系统提示词 + 历史多轮会持续占用窗口，超出部分会被截断，模型「忘事」。计算器把窗口长度、每轮增量和历史轮数代入公式，直接告诉你还能聊几轮。

## 这个工具能做什么

- 内置主流模型上下文长度对照
- 估算还能聊多少轮不超限
- 提示截断风险与临界轮次
- 辅助长对话与批量任务预算

## 怎么使用（输入说明）

1. **选模型**：从内置对照表选上下文长度。
2. **填长度**：系统提示词、每轮输入 / 输出大致 token 数。
3. **看结果**：得到可支撑轮数与截断临界。
4. **调策略**：按需压缩历史或换更长窗口模型。

## 常见问题 FAQ

**Q：token 数怎么估？**

A：中文约 1.5–2 字 / token、英文约 4 字符 / token 为粗略参考；精确值以各模型 tokenizer 为准。

**Q：窗口越长越好吗？**

A：更长窗口能装更多历史，但长上下文推理更慢更贵，按任务实际需要选即可。

**Q：数据更新频率？**

A：模型上下文长度为人工维护快照，新模型上线请以厂商文档为准。
