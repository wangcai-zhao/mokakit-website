## 新增基础设施：`npm run check:units`（可复用）

- `scripts/check-units.mjs` + `scripts/ts-resolve.mjs`（已挂 package.json）。
- **解决的真问题**：FEATURED_PAIRS 里写错一个单位 id，Astro 构建会**静默跳过**那一页——不报错、不生成、极难发现。脚本 1 秒内抓出来，不用等 40 秒构建。
- 校验四层：① 类目/单位 id 唯一 + 基准单位 factor 必须为 1；② 换算对引用有效 + 长尾 slug 唯一；③ **43 条系数抽样断言**（防手滑写错数量级）+ 温度多取值点断言（含 -40°C = -40°F 这个零点校验）；④ 子页产出数量必须等于换算对数量（数量不等即说明有页被静默吞了）。

### 关键技巧：不启动 Astro 直接跑 src/ 下的 TS 数据模块
`node --experimental-strip-types --import ./scripts/ts-resolve.mjs xxx.mjs`
- Node 22 的 strip-types 只擦类型，**不做模块解析**，所以 TS 风格的无扩展名导入（`from '../types'`）会 ERR_MODULE_NOT_FOUND。
- 解法：`scripts/ts-resolve.mjs` 用 `node:module` 的 `registerHooks()` 补全 `.ts/.tsx/index.ts` 后缀。
- 校验/数据脚本一律走这条路，比跑构建快 40 倍。

### 踩坑
- Bash 工具的 heredoc（即使 `<<'EOF'`）会把 JS 模板字符串 `${...}` 解析成 shell 替换 → `Bad substitution`。**写脚本一律用 Write 工具，不要用 heredoc**。
- Git Bash 无 `sleep` 命令（`sleep: command not found`），别用它等构建。
- 本机 4321-4325 端口已被历史 preview 进程占满，新 preview 落在 **4326**。

### 2. 顺手修了两个**原有真 bug**
- **`<kv k="..." v="..."></kv>` 从来没生效**：模板字符串里这是字面自定义元素标签，根本不会调用同名的 `kv()` 函数，属性 k/v 也不是文本节点 → **「🚀 上线与备案状态」整张卡片一直渲染成空白**（CSS 里明明写了 `.kvrow` 样式，说明作者本意是函数调用）。已全部改成 `${kv('x','y')}`。**教训：模板字符串里想调函数必须 `${fn()}`，写成标签形态会静默失效、不报错。**
- **公开副本脱敏漏网**：规则只替换「旺财先生」，而手写文案里大量是「旺财确认」（不带"先生"）→ 漏出 3 处；`repo: D:/WorkBuddy/website` 本地路径也没被 `C:\\Users` 规则覆盖。已改成 `/旺财先生|旺财|大美丽/g` 和通用盘符路径正则 `[A-Za-z]:(\\|/)(Users|WorkBuddy)(\\|/)[^"，,）)]*`。**public/workbench.html 会随站点发布，加手写文案后必须回头核对脱敏规则。**
