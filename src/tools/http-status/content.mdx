## HTTP 状态码分类原理

HTTP 状态码是服务器对请求的三位十进制响应码，首位数字表示类别：

1xx 信息 / 2xx 成功 / 3xx 重定向 / 4xx 客户端错误 / 5xx 服务端错误

## 这个工具能做什么

- 按具体状态码或类别查询含义
- 展示常见码的原因与排查方向
- 本地查询，不上传

## 怎么使用（输入说明）

1. **输入状态码**：填具体数字（如 404）或选类别浏览。
2. **查看**：得到该码的含义、常见原因与处理建议。

## 状态码分类依据什么

首位数字决定大类：2xx 表示成功处理；3xx 需进一步操作（重定向）；4xx 是请求方问题（如 404 资源不存在、401 未认证）；5xx 是服务端故障（如 500 内部错误、502 网关错误）。

## 计算实例

例：404 = 请求的资源不存在；500 = 服务器内部错误；301 = 永久重定向到新地址。

## 常见问题 FAQ

**Q：状态码分类依据什么？**

A：按首数字划分：1xx 信息、2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务端错误。本表收录开发与调试中最常见的一批，并非全部状态码。

**Q：这是离线可用的吗？**

A：是的。数据直接内置于页面，无需联网即可搜索查询，适合无网络环境下的开发参考。
