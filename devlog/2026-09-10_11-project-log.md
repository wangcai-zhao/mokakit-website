## 二、已完成事项

### 1. MCP 形态调研（09-10）
- 协议：**Streamable HTTP + JSON-RPC 2.0**，零外部依赖（只用 `node:http` / `node:crypto`）。
- 工具清单：**14 个计算型 tool** + 1 个 search-first 入口 `mokakit_search`。
  - 计算类：`income_tax_cn` / `bonus_tax_cn` / `social_security_cn` / `vat_general_cn` / `mortgage_schedule_cn` / `mortgage_early_repayment_cn` / `retirement_age_cn` / `after_tax_salary_cn` / `deposit_interest_cn` / `deed_tax_cn` / `overtime_pay_cn` / `pension_estimate_cn` 等。
  - 入口类：`mokakit_search` 在 ~100 个工具目录里按词检索，告诉 AI "该调哪个具体 tool"。
- 复用方式：直接 `import` `src/lib/*.ts` 的纯函数（`china-tax` / `china-social-security` / `china-vat` / `mortgage` / `china-calc-extra`），零重写。
- 运行：监听 `MCP_PORT`（默认 18700），可选 Bearer 鉴权（不设 `MCP_TOKEN` 就不校验，本地调试省事）。
- 生产态：`mcp/build.mjs` 用 esbuild 把 `server.mjs` + 依赖的 `.ts` 纯函数打包成 `deploy/mcp/server.mjs`（target node18，自包含），启动「优先读 `catalog.json`」，彻底不依赖 `src/` 和 TS 运行时。

### 2. 体验版承载 MCP 的成本测算（09-10）
- 云托管常驻 0.25C/0.5G：CPU 180 核时×55 + 内存 360 GB时×32 = **21420 点/月** → 体验版 3000 点只够 **约 4 天**，直接否掉。
- HTTP 云函数（512MB / 300ms / 50KB 响应）：约 **0.056 点/次** → 日 100 次 ≈ 170 点/月，跑得动。
- 单价参考（CloudBase 购买指南）：云函数 13.3 点/万次 + 0.11108 点/GBs；外网出流量 800 点/GB。
- **结论**：体验版下 MCP 只能走 HTTP 云函数，不能走云托管常驻。
