## 为什么需要统计代码行数

看项目规模、写周报「这周写了 2000 行」、估算评审工作量、或者单纯好奇「这文件到底多少有效代码」，都需要行数统计。但 `wc -l` 只给总行数，分不清注释、空行和真代码。

本工具把源码按「总行 / 代码 / 注释 / 空行」拆开统计，自动识别常见注释语法，粘贴即出。

## 概念与公式

行数分类（按行，可重叠归属）：

- **总行**：文件所有行（含末尾换行前的每一行）。
- **空行**：去除首尾空白后为空。
- **注释行**：整行或行尾的注释，依语言而定。

支持注释语法：

- 行注释：`//`、`#`、`;`（依语言启发式，取最常见组合）。
- 块注释：`/* ... */`、HTML `<!-- -->`、Python/JS 文档字符串 `"""..."""`。

统计是逐行扫描 + 块注释状态机，不编译、不执行代码。注意：它衡量「体量」而非「质量」。

## 细分场景

- **项目汇报**：给领导/客户一个规模数字。
- **评审预估**：行数多的 PR 重点看。
- **自查膨胀**：发现注释占比异常高可能意味着代码该重构。

## 怎么用本工具

把源码贴入输入框（可指定语言或自动识别），结果即时显示四类行数及占比条。支持多语言启发式识别常见注释风格。

## 常见场景与实例

**例：JS 片段**
```
// 计数器
function count() {   /* 主体 */
  return 1; // 返回
}
```
统计为：代码 3 行、注释 2 行、空行 0 行、总行 5 行（行尾注释计入注释）。
