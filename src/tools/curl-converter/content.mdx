## curl 命令转换是什么

浏览器开发者工具能「复制为 cURL」，但这段代码没法直接放进项目里。转成各语言的 HTTP 客户端代码，联调效率立刻翻倍。

## 这个工具能做什么

- 转成 fetch / Axios / Python / Go / PHP 五种代码
- 自动识别方法、请求头、请求体
- JSON 与表单请求体分别处理
- 支持多行续写的命令

## 怎么使用（输入说明）

1. **粘贴 curl 命令**
2. **点选目标语言**
3. **核对 URL 与请求头数量**
4. **复制代码**

## 使用时的几个注意点

- 不支持 -F 文件上传等复杂参数
- Authorization 会被如实带出，别把含密钥的命令贴到公开地方
- Go 版本会自动引入 strings 包

## 实例

一个带 Bearer Token 的 POST 请求，转成 fetch 后 headers 与 body 都已填好。

## 常见问题 FAQ

**Q：支持哪些 curl 参数？**

A：支持 -X / -H / -d / --data-raw / -u / -A / -F 等常见参数。不支持 cookie jar、证书指定等复杂用法，遇到解析不对的地方手动改一下即可。

**Q：请求体是 JSON 还是表单怎么判断？**

A：看 Content-Type 请求头：带 application/json 就按 JSON 处理，带 x-www-form-urlencoded 就解析成表单键值对。

**Q：复制的命令带反斜杠换行能识别吗？**

A：能。工具会先把命令里的续行符和引号处理好再解析，浏览器复制出来的多行命令可以直接粘。
