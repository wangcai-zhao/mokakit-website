## 哈希（摘要）算法原理

哈希把任意长度输入映射成固定长度摘要，具有「输入微小变化→输出完全不同」「不可逆」特性。本工具实现 MD5（128 位）、SHA-1（160 位）、SHA-256（256 位）、SHA-384（384 位）、SHA-512（512 位）五大家族，均为纯 JS 实现，不依赖 Web Crypto，HTTP 环境同样可用

## 这个工具能做什么

- 对文本计算 MD5 / SHA-1 / SHA-256 / SHA-384 / SHA-512 摘要（可多选同时算）
- 对文件计算摘要：4MB 分片增量读入，大文件不占内存，适合校验下载文件完整性
- 十六进制结果支持大写/小写切换与一键复制（默认小写，对齐命令行习惯）
- 用于完整性校验、去重、指纹；全部本地计算，不上传

## 怎么使用（输入说明）

1. **输入内容**：粘贴文本，或在「计算文件摘要」区选择文件。
2. **选算法**：可多选，结果卡实时显示对应摘要；MD5 标注了仅兼容用途。
3. **切换大小写**：点「大写输出」开关，复制的是当前显示形式。
4. **比对**：把结果与官方提供的摘要值逐字符比对，一致即未被篡改。

## 哈希和加密是一回事吗

不是。加密可解密（有密钥），哈希不可逆、只用于校验「内容是否被改动」。校验文件时对比两端摘要是否一致即可。

## 计算实例

对 "hello" 计算：

- MD5：`5d41402abc4b2a76b9719d911017c592`（32 位）
- SHA-1：`aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d`（40 位）
- SHA-256：`2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824`（64 位）

改动一个字母（"hellp"），输出完全改变，这就是雪崩效应。

## 常见问题 FAQ

**Q：哈希和加密是一回事吗？**

A：不是。加密是可逆的（有密钥就能还原原文），哈希是单向的（无法从摘要反推原文），主要用于校验完整性。本工具做的是哈希，不能逆向解密。

**Q：支持哪些算法？MD5 安全吗？**

A：支持 MD5、SHA-1、SHA-256、SHA-384、SHA-512。MD5 已被证明存在严重碰撞漏洞，不再适合安全用途，仅建议用于兼容旧系统或校验完整性；SHA-1 同理；日常校验请优先 SHA-256 及以上。

**Q：可以计算文件的哈希吗？**

A：可以。在「计算文件摘要」区选择文件，按 4MB 分片增量计算并显示进度，适合校验大文件，结果与 certutil、sha256sum 等命令行工具一致。
