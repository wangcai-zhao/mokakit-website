## 为什么需要 Slug 生成

写博客、发产品、做栏目页时，URL 里的标题部分最好是一串干净的小写连字符，比如 `how-to-bake-bread` 而不是 `How%20To%20Bake%20Bread`。好的 slug 利于 SEO、好看、还能直接当锚点。但手动把「2026 年最值得买的 10 款键盘！」改成 slug 又慢又容易出错。

本工具把任意文章标题、中文/英文混合文本一键转成 URL 友好的 slug，粘贴即出，复制即用。

## 概念与公式

Slug 是 URL 路径里用于标识资源的「可读字符串」。标准处理步骤：

1. 转小写；
2. 去除重音符号（é → e）；
3. 把空格、下划线、标点统一替换为连字符 `-`；
4. 去掉 URL 不允许或易出错的字符（如 `& ? % #`）；
5. 折叠多余连字符、去掉首尾连字符。

本工具对非 ASCII（如中文）默认采用「保留 Unicode 字母 + 连字符」的安全策略（搜索引擎能正常索引中文路径），你也可切换成「仅 ASCII」模式把非 ASCII 直接剔除。

## 细分场景

- **博客 / 文档**：每篇文章一个语义化 slug，便于分享和记忆。
- **电商 SKU**：把商品名转成可放在链接里的标识。
- **锚点 / 目录**：长文自动生成标题锚点 id。

## 怎么用本工具

在输入框贴入标题或任意文本，选择「保留 Unicode」或「仅 ASCII」模式，结果即时显示。可勾选「是否保留数字」「最大长度」等选项，点复制按钮贴走即可。

## 常见场景与实例

**例：中文标题**
「2026 年最值得买的 10 款键盘」→ `2026-年最值得买的-10-款键盘`（保留 Unicode）或 `2026-10`（仅 ASCII）。

**例：英文标题**
「My First Post!!!」→ `my-first-post`。
