## Markdown 渲染原理

把 # 标题、** 加粗、* 列表、&gt; 引用、代码块等标记解析为 HTML 实时预览，全程在浏览器本地完成，不上传服务器

支持常用 GFM 语法（含表格与任务列表）

## 这个工具能做什么

- 左侧写 Markdown、右侧实时预览，所见即所得
- 支持标题、列表、任务列表、表格、代码块、引用、链接、图片、删除线等 GFM 常用语法
- 语法工具栏：加粗、斜体、删除线、行内代码、代码块、链接、引用、三种列表、表格，光标处一键插入
- 一键复制渲染后的 HTML，可直接粘贴进公众号编辑器或笔记软件
- 本地渲染，不上传

## 怎么使用（输入说明）

1. **输入 Markdown**：在编辑区键入，或用上方工具栏按钮快速插入语法。
2. **查看预览**：右侧同步渲染效果。
3. **复制 HTML**：点「复制 HTML」把渲染结果粘贴进富文本编辑器；点「清空」从头开始写。

## 支持哪些 Markdown 语法

覆盖标题、加粗/斜体/删除线、有序/无序列表、任务列表、引用、行内与块级代码、链接、图片、表格、分割线等 GFM 常用子集。工具栏按钮与语法一一对应，不确定写法时点一下看示例。

## 计算实例

例：输入 "# 标题\n- 项目一\n- 项目二" 右侧渲染为带标题的列表；输入表格三行（表头 + 分隔行 + 数据行）即渲染为带框线的表格。

## 常见问题 FAQ

**Q：支持哪些 Markdown 语法？**

A：支持 GFM 常用语法：标题（# ~ ######）、加粗/斜体/删除线、有序与无序列表、任务列表（- [ ]）、表格、引用、行内与块级代码、链接、图片、分隔线等，覆盖日常写作与 README 预览所需。

**Q：可以把渲染结果复制到公众号编辑器吗？**

A：可以。点工具栏右侧的「复制 HTML」，复制的是右侧渲染后的 HTML 代码，粘贴进支持富文本的编辑器（如公众号后台、笔记软件）即可保留排版，粘贴时选择「保留源格式」效果最佳。

**Q：我的内容会被保存或上传吗？**

A：不会。Markdown 解析与渲染完全在浏览器本地进行，文本不上传，刷新页面即恢复为默认示例，适合临时草稿预览。
