## 怀孕周数计算公式

以末次月经（LMP）为起点，到今天的天数换算成「周 + 天」，并按 280 天（40 周）估算预产期：

```
距今天数 = 今天 − 末次月经
孕周     = floor(距今天数 ÷ 7)
孕天     = 距今天数 mod 7
预产期   = 末次月经 + 280 天
```

## 这个工具能做什么

它把「末次月经日期」转成医学上通用的孕周表达，用于：

- 产检进度对照（每次产检都按孕周记录）；
- 孕期里程碑（如「满 12 周」「满 28 周」）；
- 预产期的大致预估；
- 孕妇自我记录与分享。

医学上统一以 LMP 起算，而非实际受孕日，因为 LMP 更易确定。

## 怎么使用本工具

1. 在「末次月经（LMP）日期」填写日期（默认示例 2026-05-01）。
2. 结果区显示「今天怀孕 X 周 Y 天」与总天数。
3. 下方给出估算预产期（LMP + 280 天）。

## 计算详解

孕期以 7 天为一周。距今天数对 7 取商得周数、取余得天数。预产期按 LMP 加 280 天（40 周）估算，属统计学均值——约仅 5% 孕妇在预产期当天分娩，前后两周内均正常。若 LMP 晚于今天，会提示日期填反。

## 计算实例

**例 1：LMP 为 2026-05-01，今天是 2026-08-09？**

距今天数 = 100 天；100 ÷ 7 = 14 周余 2 天 → 怀孕 14 周 2 天。预产期 = 2026-05-01 + 280 天 ≈ 2027-01-26。

**例 2：刚满 7 天？**

7 ÷ 7 = 1 周余 0 天 → 怀孕 1 周 0 天。

**例 3：LMP 晚于今天？**

工具提示「末次月经日期晚于今天，请核对是否填反」，避免给出负孕周。
