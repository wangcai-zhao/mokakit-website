## UTC 转中国标准时间公式

中国标准时间（北京时间）为东八区，固定偏移 UTC+8：

```
北京时间 = UTC 时刻 + 8 小时
```

若结果超过 24:00 则进入次日；若小于 00:00 则退到前一天。本工具按此固定偏移换算，并标注「当天 / 次日 / 前一天」。

## 这个工具能做什么

它把「协调世界时（UTC）」换算成「北京时间」，用于：

- 跨国会议、国际赛事的排期对齐；
- 服务器/日志的 UTC 时间戳转本地可读时间；
- 海外平台发布时间对照；
- 任何需要「UTC → 北京」的场景。

中国大陆全国统一使用 UTC+8，无时区差异，也不实行夏令时。

## 怎么使用本工具

1. 在「UTC 小时」填 0-23，「UTC 分钟」填 0-59。
2. 结果区立即显示对应的北京时间与跨天提示。
3. 可一键复制结果。

## 计算详解

直接对分钟累加：总分钟 = (UTC时×60 + UTC分) + 480（8 小时），再对 1440 取模得当日时刻，商为跨天数。例如 UTC 20:00 → 总分钟 1200+480=1680 → mod 1440 = 240 → 04:00，跨 +1 天即次日。UTC 00:00 → 08:00 当天。由于中国不实行夏令时，该偏移常年有效。

## 计算实例

**例 1：UTC 12:00 是北京几点？**

12 + 8 = 20:00，当天晚上 8 点。

**例 2：UTC 20:00 呢？**

20 + 8 = 28 → 次日 04:00（标注「次日」）。

**例 3：UTC 00:30 呢？**

0:30 + 8 = 08:30，当天早上。
