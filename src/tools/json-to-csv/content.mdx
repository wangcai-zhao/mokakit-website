## JSON 转 CSV 原理

把对象数组的键作为表头，每个对象作为一行，值按列填充

嵌套对象/数组会序列化为字符串或由用户指定展开方式

## 这个工具能做什么

- 把 JSON 数组导出为 CSV 表格
- 处理字段不一致的异构数据
- 正确处理逗号/引号转义

## 怎么使用（输入说明）

1. **粘贴 JSON 数组**：每项是一个对象。
2. **转换**：工具提取全部字段作表头，生成 CSV，可下载。

## 内容含逗号或引号怎么办

CSV 用双引号包裹含逗号/换行的字段，内部引号再转义为两个引号，标准表格软件可正确还原，不会错列。

## 计算实例

例：[\{"name":"A","v":1\},\{"name":"B","v":2\}] → 表头 name,v，两行数据。

## 常见问题 FAQ

**Q：各条数据的字段不一致怎么办？**

A：工具会先扫描全部记录，按首次出现顺序收集所有 key 组成表头并集。某条记录缺失的字段会输出为空值，不会错位，因此字段参差不齐的数据也能安全转换。

**Q：内容里含逗号或引号会不会把表格弄乱？**

A：不会。凡是包含逗号、双引号、换行符的单元格都会用双引号包裹，内部的双引号按 CSV 标准写成两个连续双引号，Excel、WPS、Numbers 都能正确还原。

**Q：嵌套的对象或数组怎么处理？**

A：嵌套值会被序列化成 JSON 字符串填入单元格，保证信息不丢失。如需展开成多列，建议先在 JSON 格式化工具中把数据拍平后再转换。
