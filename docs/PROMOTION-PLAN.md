# MokaKit 推广与变现投放方案

> 制定：2026-11-03　｜　状态：方案（待旺财执行开户/预算决策）
> 配套代码改造：`SITE.ads.slots` 版位级开关、`AdSlot.astro` 广告标识、`scripts/check-ads.mjs` 闸门
> ⚠️ 本文不写具体返佣比例、CPM、开户链接 —— 这些随平台政策变动，一律以**官方后台当期数据**为准，避免拿旧数字做决策。

## 1. 现状盘点

| 项 | 现状 | 依据 |
|---|---|---|
| 流量来源 | 自然搜索（百度 / Bing）+ 公众号 + 少量外链 | 站点无投放历史 |
| 统计 | 百度统计（`site.ts` 已配 ID）；GA 留位未启 | `site.ts:69-74` |
| 广告 | Google AdSense 已开（`ca-pub-…4877`），3 个版位（首页中部、工具页下方 ×2 布局） | `site.ts:75-105`；`AdSlot` 使用点 |
| 联盟推广 | WorkBuddy 邀请（已有 sponsored + 披露）；**腾讯云等云厂商合作尚未接入** | `InviteCta.astro` |
| 内容资产 | 281 工具、13 博客、15 技巧、36 智能体、812 好站 | 基准文档 §1.2 |
| 变现结构 | 几乎 100% 依赖 AdSense（单一渠道风险） | 同上 |

**核心问题**：渠道单一、无付费投放经验、无 ROI 基线。所以本方案的第一目标不是"多花钱"，而是**建立可测量的最小闭环**。

## 2. 目标与指标口径

| 层级 | 指标 | 口径 | 用途 |
|---|---|---|---|
| 流量 | UV / PV | 百度统计，按渠道分组 | 判断渠道质量 |
| 参与 | 工具使用率 | 进入工具页且有交互的 UV / 工具页 UV | 区分"来了就走"与"真用" |
| 变现 | eCPM | 广告收入 / 展示 × 1000 | 版位横向比较 |
| 变现 | RPM | 广告收入 / 页面 PV × 1000 | 单页价值 |
| 联盟 | CPS 转化率 | 成交单数 / 联盟链接点击 | 判断合作价值 |
| 投放 | ROI | （收入 − 花费）/ 花费 | 决定加/减预算 |

**基线要求**：任何付费投放开始前，必须先有 2 周的自然流量 RPM 基线，否则无法判断投放是赚是亏。

## 3. A 线：腾讯云推广合作

### 3.1 为什么是腾讯云

MokaKit 的用户画像与云厂商高度重叠：开发者工具（JSON/正则/时间戳）、AI 工具（选模型、MCP 配置）、部署类需求（MCP Server 需要服务器/域名）。**"工具用完要落地"的下一步就是买云资源**，这是天然的转化路径。

### 3.2 可对接的四种形态

| 形态 | 说明 | 适配度 | 前置条件 |
|---|---|---|---|
| **推广联盟（CPS）** | 通过专属推广链接引导注册/购买，按成交返佣 | ★★★★☆ 最易起步 | 需注册腾讯云账号并申请加入推广联盟，审核主体资质 |
| **云市场 / 应用市场上架** | 把 MokaKit 的 MCP 服务或镜像作为商品上架 | ★★☆☆☆ 需产品化封装 | 需可交付的镜像/服务、售后能力 |
| **开发者社区内容合作** | 在腾讯云开发者社区发 MCP 接入教程，带站点外链 | ★★★★☆ 低成本 | 内容质量达标，遵守社区外链规则 |
| **联合活动 / 扶持计划** | 面向中小开发者的扶持、代金券联合发放 | ★★☆☆☆ 需商务对接 | 需有可量化的用户规模与联合方案 |

### 3.3 建议起步路径（推荐只做前两项）

1. **注册腾讯云账号 → 申请推广联盟**，拿到专属推广链接（后台可见当期佣金比例与结算规则）。
2. **选 3 个高意图落地页**接推广位，而不是全站铺：
   - `/developers/`（MCP 接入说明，读者本就在找部署方案）
   - `/tools/mcp-config-generator/`（配完就要部署）
   - `/tips/` 里与部署/服务器相关的文章
3. 推广位形态：**文末"延伸阅读"式文字链 + 明确标注**，不做弹窗、不做悬浮。
4. 观测 30 天：点击量、注册转化、成交单数、佣金。低于预期就停，不追加。

### 3.4 合规红线（务必遵守）

| 红线 | 要求 |
|---|---|
| 标识 | 推广链接旁必须标「广告 / 推广」或「含推广链接」，符合《互联网广告管理办法》可识别要求 |
| 披露 | 页面需说明"通过本链接购买，本站可能获得佣金，不影响你的价格" |
| 属性 | 链接加 `rel="sponsored nofollow noopener"` |
| 承诺 | 不得写"最低价""全网最便宜""保证省钱"等绝对化或承诺性表述，价格以官方页面为准 |
| 品牌 | 使用腾讯云名称/Logo 须遵守其品牌规范，不得暗示官方背书 |
| 自返 | 不得自己下单套返佣（平台明确禁止，封号风险） |

> 与现有 `InviteCta.astro` 的做法保持一致：**sponsored + 目标域名明示 + 利益关系披露 + 一切以官方为准**。这套模板可直接复用。

## 4. B 线：软广（内容型，优先做）

软广的本质是"用内容换自然流量"，成本是时间不是钱，最适合当前阶段。

### 4.1 四个内容阵地

| 阵地 | 内容形态 | 频率 | 关键约束 |
|---|---|---|---|
| **公众号**（已有「MokaKit 摩卡工具箱」） | 单工具场景文：一个真实麻烦 + 怎么用工具解决 | 每周 1 篇 | 去 AI 味、口语化、少用模板腔（旺财明确偏好） |
| **知乎 / 掘金 / CSDN** | 技术长文：MCP 接入实战、税后工资算法拆解、检索单源重构 | 每月 2 篇 | 平台反感硬广，外链放文末且需有价值 |
| **GitHub** | README 互推、提交 awesome-* 列表收录 | 一次性 + 季度维护 | 遵守列表收录规则，不刷 star |
| **小红书** | 办公/生活技巧（房贷计算、证件照、单位换算） | 每周 1–2 篇 | 真人分享感，禁"码住/亲测有效"模板腔 |

### 4.2 选题与工具绑定的原则

**一个内容只推一个工具**，且必须是"这篇内容解决的那个问题"。反面例子：讲完房贷计算顺便推 12 个工具 —— 转化率归零。

优先选题（按搜索意图强弱）：

1. 税后工资 / 年终奖 / 社保（强需求、强复算）
2. 房贷提前还款、二手房税费（决策金额大）
3. MCP 配置 / Claude 接入（开发者、与腾讯云 CPS 天然衔接）
4. 图片压缩 / 证件照（高频、社交传播强）
5. 单位换算（长尾量大、竞争低）

### 4.3 站内软性推荐（非广告位）

工具页底部已有"相关工具"（按 tags 重合度自动算）。可再加一层**场景化推荐**：
"算完房贷 → 你可能还需要：提前还款计算器 / 二手房税费"。这属于内容推荐，不是广告，不占广告位配额，也不违反 AdSense 政策。

## 5. C 线：硬广（付费，需预算决策）

### 5.1 渠道对比

| 渠道 | 形态 | 适配场景 | 风险 |
|---|---|---|---|
| **Google AdSense** | 展示广告（已在跑） | 全站变现 | 政策严，误点/诱导会封号 |
| **百度联盟** | 展示广告（国内流量主） | 国内搜索流量变现 | 需备案与资质审核；与 AdSense 同页混投需各自确认政策 |
| **腾讯广告** | 朋友圈 / 公众号文末 | 拉新、活动推广 | 需开户与资质，起投门槛较高 |
| **Google Ads** | 搜索广告 | 英文工具 / 海外流量 | 需落地页与转化追踪 |
| **必应 / 360 / 搜狗** | 搜索广告 | 长尾词补量 | 流量质量参差 |

### 5.2 投放纪律（建议写进制度）

1. **先有机、后付费**：任何渠道的自然 RPM 基线未建立前，不投付费。
2. **小额分散**：首个测试期每渠道预算设上限，跑满 2 周再评估，不追加热度。
3. **只投有转化路径的落地页**：工具页（有交互）优先于首页（只有导航）。
4. **单页广告位 ≤ 2**：已由 `scripts/check-ads.mjs` 与 `maxPerPage` 强制，防止为提收入堆版位。
5. **停投标准**：连续 14 天 ROI < 0 且无改善趋势 → 停。

### 5.3 预算模型（框架，不填数字）

```
可承受月预算 = 月广告收入 × 再投比例（建议首年 ≤ 30%）
单渠道测试预算 = 可承受月预算 × 渠道数倒数
投放盈亏线： ROI =（增量收入 − 花费）/ 花费 ≥ 0
```

首年建议把预算优先给**内容生产工具**（图片处理、AI 额度）而非直接买量——因为站点变现能力（RPM）尚未验证，买量容易亏。

## 6. 站内版位规划（对应本次代码改造）

改造后版位必须先在 `SITE.ads.slots` 登记才会投放，未登记一律不展示。

| 版位 key | 位置 | 尺寸 | 状态 | 建议 |
|---|---|---|---|---|
| `home-mid` | 首页工具网格中部 | banner | **已开** | 保持，首屏以下不干扰 |
| `tool-below` | 工具页正文下方 | banner | **已开** | 保持，用户已完成任务，干扰最小 |
| `article-bottom` | 博客/技巧文末 | rectangle | 预留关闭 | 内容页读完再展示，eCPM 通常最高；建议先小流量试 |
| `list-inline` | 列表页插入 | banner | 预留关闭 | 慎用，易被判定干扰导航 |

### 版位纪律

- **工具交互区上方不放广告**（会打断使用，且 AdSense 禁止与操作按钮混淆）；
- 每页 ≤ `maxPerPage`（当前 2）；
- 广告位固定高度，禁止因加载导致布局跳动（CLS）；
- 全部广告位带中文「广告」标识（`showLabel: true`，已实现）。

## 10. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| AdSense 账户被封 | 收入断崖 | 严守政策：不诱导、不堆版位、不放在无内容页 |
| 广告过多伤 SEO/CWV | 排名下降 | `maxPerPage=2` + 固定高度 + 闸门校验 |
| 联盟链接被判定为软文未标识 | 合规处罚 / 平台降权 | sponsored + 广告标识 + 披露 |
| 腾讯云推广政策变动 | 返佣下降 | 不把收入押在单一联盟，保持 AdSense + 内容并行 |
| 投放亏钱 | 预算浪费 | 先基线后投放、小额分散、14 天停投纪律 |
| 内容软广被判广告 | 平台限流 | 内容以解决问题为主，外链克制，不写促销话术 |

---

## 11. 一句话结论

**先合规、再内容、后付费**：把站内版位与标识做扎实（本次已完成），用内容换自然流量建立 RPM 基线，再拿腾讯云 CPS 这类"零成本、按成交付费"的联盟做第一增量；付费投放留到有基线之后，且预算不超过广告收入的 30%。
