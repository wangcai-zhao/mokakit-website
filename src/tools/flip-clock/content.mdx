## 翻页时钟原理

翻页时钟用纯 CSS 3D 变换（rotateX）还原经典机械翻牌效果：每当秒数变化，对应数字卡片以底部为轴从 90° 翻转到 0°，露出新数字。整个过程由浏览器 GPU 硬件加速，每秒翻动一次，稳定流畅。

## 这个工具能做什么

- 经典翻牌动画显示当前时间（时:分:秒），怀旧又吸睛
- 支持 12 / 24 小时制与多套主题（黑金、极简白、摩卡、赛博）
- 一键全屏，可常驻桌面、直播背景或大屏展示

## 怎么使用

1. 选择喜欢的主题配色。
2. 如需显示「上午 / 下午」，切换为 12 小时制。
3. 点击「全屏」即可把整块屏幕变成翻页时钟；按 Esc 退出。

## 翻页时钟 vs 数字时钟

数字时钟是连续静态大字，适合一眼读时；翻页时钟强调「翻动」的仪式感与视觉美感，每秒翻牌一次，更适合装饰、直播和怀旧场景。两者都用本地时间，精度一致，按喜好选择即可。

## 使用实例

做视频直播时把翻页时钟投到副屏当背景，黑金主题极具质感；把电脑接上闲置显示器挂在厨房或玄关，秒变一面会翻牌的装饰钟。

## 常见问题 FAQ

**Q：翻页动画流畅吗？会卡顿吗？**

A：本工具用纯 CSS 3D 变换实现翻牌动画，由浏览器硬件加速，正常情况下稳定 60fps，几乎不占用系统资源，可长期常驻桌面或投放大屏。

**Q：为什么有时候翻动后数字「跳」了一下？**

A：翻页时钟每秒翻动一次显示新的秒数，这是翻牌机制的固有表现，并非故障。若想看连续平滑走时，可改用数字时钟或模拟时钟。

**Q：可以常驻在屏幕上当装饰吗？**

A：可以。点击「全屏」后它就是一个纯净的翻页时钟，适合直播背景、会议室或卧室大屏；按 Esc 退出全屏。
