## 为什么需要端口查询

排查服务起不来、防火墙没通、容器端口映射错，第一件事往往是确认「某个端口号对应什么服务」。比如 5432 是 Postgres、6379 是 Redis、9200 是 Elasticsearch。记不住就靠查。

本工具提供一份常用端口 → 服务名对照表，输入端口号查服务，或反过来输入关键字查端口，省去翻 RFC 或搜索引擎。

## 概念与公式

端口（Port）是 TCP/UDP 协议里区分同一台机器上不同服务的 16 位整数，范围 `0–65535`：

- **0–1023 系统端口（Well-known）**：HTTP 80、HTTPS 443、SSH 22、DNS 53 等，需管理员权限绑定。
- **1024–49151 注册端口**：许多中间件和数据库在这里（如 3306 MySQL、27017 MongoDB）。
- **49152–65535 动态/私有端口**：客户端临时端口（ephemeral）。

查表本质是「端口号 ↔ 服务名」的双向映射，不涉及计算。

## 细分场景

- **排障**：服务连不上，先确认端口是不是被占、是不是配错。
- **写防火墙规则**：准确放行需要的端口，避免大开 0–65535。
- **看 `netstat`/`ss` 输出**：把陌生的-established 端口对上服务名。

## 怎么用本工具

在搜索框输入端口号（如 `3306`）或关键字（如 `redis`），下方即时过滤出匹配的服务名、协议（TCP/UDP）和说明。支持模糊匹配。

## 常见场景与实例

**例：确认数据库端口**
输入 `5432` → PostgreSQL（TCP）；输入 `6379` → Redis（TCP）。

**例：关键字反查**
输入 `ssh` → 22/TCP；输入 `dns` → 53/TCP+UDP。
