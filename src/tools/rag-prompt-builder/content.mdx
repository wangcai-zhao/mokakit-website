## RAG 提示词构建器的原理

RAG 的核心是把检索到的资料塞进提示词，再要求模型「只依据资料作答并标注出处」。构建器把这套固定结构（角色 + 指令 + 上下文占位 + 引用约束）参数化，让你不必每次从零拼，也减少漏掉「必须引用」这种关键约束。

## 这个工具能做什么

- 生成带 context / question 占位符的模板
- 一键开启「必须标注出处」约束
- 适配自有知识库问答场景
- 复制进你的 RAG 管线

## 怎么使用（输入说明）

1. **填角色与指令**：模型以什么身份、按什么规则回答。
2. **设引用格式**：选择脚注 / 方括号等出处标注方式。
3. **开关约束**：按需开启「只依据资料、未知就说不知道」。
4. **生成复制**：得到含占位符的模板。

## 常见问题 FAQ

**Q：占位符怎么用？**

A：运行时把 context 替换成检索到的文本、question 替换成用户问题，再整体发给模型即可。

**Q：能保证模型真引用吗？**

A：不能 100% 保证，但「必须标注出处」约束能显著提升引用率；强相关证据仍建议人工核对。

**Q：和向量库有关吗？**

A：本工具只管提示词文本，检索与向量库由你现有管线负责。
