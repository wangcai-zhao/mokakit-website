## 智能体角色设定生成器的原理

多智能体协作翻车，常见原因是「人设」模糊：谁负责什么、能调哪些工具、不能越界到哪里说不清。角色设定生成器把姓名、领域、性格、目标、边界、工具拆成字段，产出一张人设卡，既是系统提示词也是团队文档。

## 这个工具能做什么

- 结构化产出智能体角色卡
- 明确目标、边界与可用工具
- 适配多智能体协作场景
- 可直接当系统提示词用

## 怎么使用（输入说明）

1. **填基础信息**：名称、所属领域、性格基调。
2. **填目标与边界**：它负责什么、绝不做什么。
3. **列工具**：它被授予哪些能力。
4. **生成**：得到一张人设卡文本。

## 常见问题 FAQ

**Q：和多智能体框架什么关系？**

A：本工具产出「角色定义」，你再把它粘进 CrewAI / AutoGen / MetaGPT 等框架的 agent 配置里。

**Q：边界真的能限制模型吗？**

A：边界是软约束，靠提示词生效；关键权限仍要在工具层做硬隔离。

**Q：会保存吗？**

A：不会，本地生成。
