## 温度换算公式

华氏 F = 摄氏 C × 9/5 + 32

摄氏 C = (华氏 F − 32) × 5/9

开尔文 K = 摄氏 C + 273.15

## 这个工具能做什么

- 在摄氏、华氏、开尔文之间互转
- 给出三套温标的对应值
- 说明换算中的偏移与零点差异

## 怎么使用（输入说明）

1. **输入温标与数值**：如「摄氏 25」。
2. **目标温标**：勾选要转换到的温标，实时显示。

## 有没有摄氏和华氏相等的温度

令 C = F，代入得 C = C × 9/5 + 32 → C = −40。所以 −40℃ = −40℉，这是两温标唯一相等的点。

## 计算实例

例：体温 37℃ → 华氏 = 37 × 9/5 + 32 = 98.6℉；开水 100℃ = 212℉。

## 常见问题 FAQ

**Q：摄氏度和华氏度怎么互相换算？**

A：华氏转摄氏：℃ = (℉ − 32) × 5 ÷ 9；摄氏转华氏：℉ = ℃ × 9 ÷ 5 + 32。日常心算可以用近似法：华氏度减 30 再除以 2 就接近摄氏度，例如 80℉ 约等于 25℃，实际是 26.7℃。

**Q：开尔文为什么没有度数符号？**

A：开尔文是国际单位制的热力学温度基本单位，本身就是绝对温标，写作 K 而不是 °K。它以绝对零度为起点，换算关系是 K = ℃ + 273.15，所以 0K 约等于 −273.15℃，是理论上的温度下限。

**Q：有没有摄氏和华氏相等的温度？**

A：有，就是 −40 度。−40℃ 恰好等于 −40℉，这是两种温标唯一的交点。你可以在本工具里输入 −40 并切换单位来验证这个结论。
