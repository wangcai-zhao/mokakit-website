## CSV 与 JSON 互转原理

CSV 是带分隔符的文本表；JSON 是结构化对象。互转时首行表头映射为键，每行映射为一个对象（或二维数组）。

## 这个工具能做什么

- CSV 转 JSON、JSON 转 CSV
- 可选分隔符与表头
- 本地运行，不上传

## 怎么使用（输入说明）

1. 选转换方向。
2. 粘贴源数据，CSV 可设分隔符与表头。
3. 查看或复制结果。

## 含逗号或换行的字段怎么处理

字段内含分隔符或换行时须用双引号包裹，内部引号用两个引号转义；本工具严格按此规则解析与生成。

## 计算实例

表头 a,b 与数据 1,2 两行，会转成「每行一个对象、键取自表头」的结构；反向则把对象数组还原为 CSV 文本。

## 常见问题 FAQ

**Q：JSON 转 CSV 表头怎么定？**

A：自动合并所有对象的键作为表头，缺失字段留空。

**Q：支持分号分隔吗？**

A：支持，CSV 转 JSON 可自定义单字符分隔符（如欧洲常用的分号）。
