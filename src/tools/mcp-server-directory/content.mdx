## MCP 服务器清单的原理

MCP 生态在快速膨胀，但 Server 散落在 GitHub 各处，新手很难一眼看清「有哪些、能接什么」。清单按用途维度把热门 Server 收拢成一张表，配链接与定位，让接入从「盲搜」变成「对照挑」。

## 这个工具能做什么

- 按维度整理热门 MCP Server
- 每条附仓库与定位
- 直达 Claude / Cursor 可接的实现
- 纯静态，随时检索

## 怎么使用（输入说明）

1. **选维度**：官方 / 数据库 / 云 / 开发等。
2. **看清单**：浏览该维度下的 Server。
3. **点链接**：跳去仓库看接入文档。
4. **挑着接**：按需求选合适的 Server。

## 常见问题 FAQ

**Q：清单全吗？**

A：收录的是各维度代表项，非全量；MCP 生态更新极快，新 Server 持续出现。

**Q：这些 Server 安全吗？**

A：链接均指向官方仓库，但实际运行请自行审阅代码与权限，尤其涉及文件 / 网络的工具。

**Q：怎么接？**

A：在支持 MCP 的客户端（如 Claude Desktop、Cursor）配置对应 Server 的启动命令或 URL 即可。
