## 为什么父母总好奇孩子能长多高

「随爸还是随妈」是全家都爱聊的话题。身高确实主要由遗传决定，但也有可量化的经验公式能估算成年身高的「遗传中点」。提前知道这个区间，既能管理预期，也能判断后天努力（营养、运动、睡眠）有没有把潜力用足。

本工具输入父母身高和孩子性别，给出预测身高和常见波动范围。

## 预测公式长什么样

常用「靶身高」公式，基于人群统计：

```
男孩 = (父高 + 母高) ÷ 2 + 6.5cm
女孩 = (父高 + 母高) ÷ 2 − 6.5cm
```

同父母背景下男孩平均比女孩高约 13cm，公式把中点对称分到两边（各 6.5cm）。这是经验常数，不同种族略有差异。

## 预测准吗，误差多大

只是遗传潜力的**中点估算**，不是定数。实际身高受很多因素影响，通常存在约 **±5cm** 的波动：

- 营养充足、运动规律、睡眠好 → 可能接近甚至略超上限
- 长期营养不良、反复生病、睡眠不足 → 可能低于下限

所以本工具给出「预测值 ± 5cm」的区间，比单个数字更诚实。

## 本工具怎么用

三个输入：

1. 父亲身高（cm）
2. 母亲身高（cm）
3. 孩子性别（男孩 / 女孩）

结果给预测成年身高和波动范围两块，预测值高亮。

## 后天能突破遗传吗

能在一定程度上。身高的「天花板」大致由遗传定，但「能长到多高」看后天：

- 蛋白质、钙、维生素均衡摄入
- 跳绳、篮球等纵向运动刺激骨骼
- 生长激素主要在深睡时分泌，睡眠关键
- 慢性疾病、早熟会影响终身高

所以公式只是趋势线，认真养、好好睡，孩子有机会站上区间上沿。
