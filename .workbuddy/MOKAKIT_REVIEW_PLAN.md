# MokaKit 体验诊断与改进路线图（2026-08-16）

> 旺财视角：首页素、配色差意思。大美丽（速构构）基于实代码体检给出结论与计划，待对齐后动手。

## 一、体检结论（基于代码实查，非凭印象）

技术底盘**扎实，不用返工**：系统字体零 webfont（保 LCP）、全本地计算不上传、JSON-LD + sitemap、合规页脚、双主题防闪。短板集中在「观感 / 品牌 / 首屏引导 / 留存」四块。

1. **配色（核心痛点）**
   - `primary` 是低彩度可可棕 `oklch(45% 0.092 48)`，整体 hue 48–70 几乎单色，缺对比、缺节奏。
   - `secondary`（拿铁焦糖）、`accent`（蜜桃粉）已在 `global.css` 定义，但 **全站 `.astro` 组件零使用**（grep 确认命中 0）。最出彩的两个色被冻住。
   - `--depth:0 / --noise:0` 全平表面 + 1px 灰边 → 强化「素」「平」。
2. **首页信息架构**
   - Hero 只有：标语 + 描述 + 搜索框 + 收录数，纯文字无视觉锚点。
   - 下接 9 个分类卡片平铺，无场景化/热门/最近使用，首屏对 100 工具毫无筛选与故事。
3. **品牌个性**
   - 名「摩卡」却无咖啡语言（无插画、无暖纹理；logo 是通用 lucide 咖啡杯），slogan 也是通用句。品牌资产沉睡。
4. **动效与生命感**：除 hover 外几乎无；整页缺呼吸感。
5. **留存/回访**：无最近使用/收藏（localStorage 可做且隐私友好）、无订阅、counter 极简。

八维度评分见对话内体检图（现状 25–90，目标约 80）。

## 二、优先级路线图

### P0 — 品牌与配色焕新（投入小、观感变化最大）
- 激活 `secondary` / `accent`：用于图标底、标签、secondary 按钮、进度条、空状态插画点缀。
- 提 `primary` 彩度与对比（chroma 0.092 → ~0.13），暗色主色同步提亮。
- 引入分类点缀色（开发/转换/计算/时间/生活/安全 各一主题色），仅用于图标底与标签，主色仍守摩卡棕。
- 建立轻量品牌插画系统（咖啡杯+蒸汽 SVG / 暖纹理），用于 Hero 与空状态。
- 重做 Hero：左文案 + 右插画/动效时钟，加「为什么选 MokaKit」三要素。

### P1 — 首页信息架构重构
- 场景化分组：常用 / 上班族 / 开发者 / 生活，替代纯分类平铺。
- 热门榜（counter 聚合）+ 最近使用（localStorage）。
- 精选合集卡片（如「个税社保一条龙」）。

### P1 — 微交互与生命感
- 卡片入场 / 滚动揭示动画、按钮按压反馈、图标 hover 微动。
- 时钟之外增加动态元素（呼应财运主题的每日一句）。

### P2 — 留存与回访
- 最近使用 / 收藏（localStorage，隐私友好）；分享卡片；邮件订阅（待定，需表单后端）。

## 三、暂缓 / 不动
- `mokakit.cn` 备案接入（待批）；技术性能/SEO 已达标不返工；多语言 i18n、账户系统（既定不做）。
