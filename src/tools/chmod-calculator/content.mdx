## chmod 权限计算器是什么

Linux 权限是三组（所有者、所属组、其他人）乘三种（读 4、写 2、执行 1）的组合，加起来就是一个八进制数字。

## 这个工具能做什么

- 勾选读写执行，实时得到数字与符号表示
- 支持 setuid / setgid / sticky 特殊位
- 八组常用预设一键切换
- 同时给出数字形式与符号形式的 chmod 命令

## 怎么使用（输入说明）

1. **点预设，或直接勾选权限**
2. **看符号表示与数字**
3. **复制对应形式的 chmod 命令**

## 使用时的几个注意点

- 目录必须有 x 才能进入
- 777 在生产环境基本等于事故
- 私钥和配置文件建议 600

## 实例

勾选所有者读写执行、组和其他人读执行，得到 755，符号表示 rwxr-xr-x。

## 常见问题 FAQ

**Q：755 和 644 该怎么选？**

A：目录和可执行文件用 755（所有者全权限，其他人可读可执行）；普通文件用 644（所有者可读写，其他人只读）。私钥、配置文件收紧到 600。

**Q：目录为什么必须有 x 权限？**

A：目录的 x 表示「能否进入」。没有 x 权限，即使有 r 权限也 cd 不进去、访问不了里面的文件。

**Q：sticky 位是干嘛的？**

A：典型场景是 /tmp：所有人都能写，但只能删除自己创建的文件。权限数字表现为 1777。
