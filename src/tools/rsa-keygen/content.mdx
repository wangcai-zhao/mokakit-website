## RSA 密钥原理

RSA 基于大素数乘积难分解：公钥 (n,e)、私钥 (n,d)，n = p × q

签名/加密用公钥，解密/验签用私钥

## 这个工具能做什么

- 生成 RSA 公钥/私钥对
- 导出 PEM 等常用格式
- 本地生成，私钥不上传

## 怎么使用（输入说明）

1. **选择密钥长度**（如 2048 / 4096 位）。
2. **生成**：得到公钥与私钥，可复制或下载保存。

## 格式能被 OpenSSL 用吗

本工具导出的 PEM（-----BEGIN RSA PRIVATE KEY----- 等）与 OpenSSL 兼容，可直接用于 SSH、HTTPS 证书与签名场景。私钥务必离线保管。

## 计算实例

例：选 2048 位生成，得到 id_rsa（私钥）与 id_rsa.pub（公钥），公钥可公开分发，私钥本地留存。

## 常见问题 FAQ

**Q：生成的私钥会传到服务器吗？**

A：不会。密钥完全在浏览器本地用 Web Crypto API 生成和导���，本工具不发任何请求，私钥不会离开你的设备。但请勿把测试私钥用于真实生产环境。

**Q：生成的格式能被 OpenSSL 使用吗？**

A：可以。导出的公钥为 SPKI PEM（BEGIN PUBLIC KEY），私钥为 PKCS#8 PEM（BEGIN PRIVATE KEY），均为标准格式，可直接用于 OpenSSH / OpenSSL / 各类编程语言。
