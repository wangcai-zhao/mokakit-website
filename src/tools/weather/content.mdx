# 天气查询

出门前看一眼天气，几乎是每天都会做的事。可惜很多天气站要么弹窗广告满天飞，要么要先注册登录、授权一堆权限，甚至偷偷收集你的位置。这个工具反着来：**输个城市名，点查询，结果就出来了**，不注册、不授权、不收集。

## 为什么需要随时查天气

天气不是「知道了就行」的信息，它直接决定你今天怎么穿、带不带伞、要不要改行程：

- **通勤上班**：早上看一眼，知道要不要提前出门避雨，或者多穿一件。
- **洗衣服**：看未来几小时有没有雨，阳台晾的衣服才不会被淋。
- **出行旅行**：落地前查目的地天气，行李里衬衫还是羽绒服一目了然。
- **运动健身**：高温、雾霾、大风天，跑步计划该不该取消心里有数。

问题在于，很多人查天气的入口被各种 App 绑架了——弹窗、推送、信息流，查个温度要被喂半天无关内容。一个干净、即查即走的天气工具，恰恰是日常最高频的需求之一。

## 天气数据到底是怎么来的

你看到的「北京 26℃ 多云」，背后不是某个人工报的，而是一整套**数值天气预报（NWP）**算出来的。

全球有几十个气象机构（德国的 DWD、美国的 NOAA、法国的 MeteoFrance 等）每天用超级计算机跑大气模型，把温度、湿度、气压、风速等变量推进求解，得到未来一段时间的预报网格。本工具的数据源 **Open-Meteo** 把这些机构的预报产品做成了**免费、开放、支持浏览器跨域调用**的接口，所以才能做到「免 API Key、前端直接取」。

它用一套叫 **WMO 天气代码** 的数字表示天气现象：比如 `0` 代表晴、`3` 代表阴、`61` 代表小雨、`95` 代表雷暴。工具把这串数字翻译成你看得懂的中文和 emoji 图标，不用去查术语表。

## 当前天气、体感、湿度、风：每个指标什么意思

查询后会给你四组核心数据，分别回答不同的问题：

- **实时温度**：此刻气温，单位摄氏度。
- **体感温度**：考虑了风速和湿度后，皮肤实际感到的冷热。冬天风一大，体感会比实测低好几度；夏天湿度高，体感比实测更闷热。
- **湿度**：空气里水分占比。超过 70% 会明显觉得潮，低于 30% 容易干。
- **风速**：单位公里/小时（km/h）。一般 20–30 km/h 就能吹乱头发，超过 60 km/h 就属于大风预警级别了。

下面还有一行 **7 天预报**：每天的最高温、最低温、天气图标，以及降水概率（%）。降水概率那一栏特别实用——它直接告诉你「带伞的必要性」有多大。
