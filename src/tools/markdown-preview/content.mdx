## Markdown 渲染原理

把 # 标题、** 加粗、* 列表、&gt; 引用、代码块等标记解析为 HTML 实时预览

支持常用 GFM 语法

## 这个工具能做什么

- 左侧写 Markdown、右侧实时预览
- 支持标题、列表、表格、代码等
- 本地渲染，不上传

## 怎么使用（输入说明）

1. **输入 Markdown**：在编辑区键入。
2. **查看预览**：右侧同步渲染效果。

## 支持哪些 Markdown 语法

覆盖标题、加粗/斜体、有序/无序列表、引用、行内与块级代码、链接、图片、表格、分割线等 GFM 常用子集。

## 计算实例

例：输入 "# 标题\n- 项目一\n- 项目二" 右侧渲染为带标题的列表。

## 常见问题 FAQ

**Q：支持哪些 Markdown 语法？**

A：支持常见语法：标题（# ~ ######）、加粗/斜体、有序与无序列表、引用、行内与块级代码、链接、分隔线等，覆盖日常写作所需。

**Q：我的内容会被保存或上传吗？**

A：不会。Markdown 解析完全在浏览器本地进行，文本不上传，刷新页面即清空，适合临时草稿预览。
