## 为什么需要「免费 API 清单」

做 demo、练手项目、写技术博客时，最缺的不是代码，而是**真实可跑的数据**。自己造假数据太假，接商业 API 又要签约付费。这份清单挑的都是**免费或免费额度友好**的开放接口，注册成本低，适合给项目快速接上真实世界的数据。

## 怎么选接口

- **纯前端原型**：优先选免 key、支持 CORS 的，比如 JSONPlaceholder、REST Countries、Open-Meteo、Dog CEO。
- **需要 key 的**：NASA、TMDB、Unsplash 这类要自己去官网申请 key；**key 绝不能写进前端代码**，应通过自己的后端代理转发。
- **关注限制**：免费档通常有速率上限或仅限非商用，商用前务必核对许可。

## 编辑精选（按场景）

- **做国际化/地址功能** → `REST Countries`：国旗、货币、语言、经纬度一应俱全。
- **做天气/本地化** → `Open-Meteo`：免 key，温度降水风速齐全；`IPinfo` 按 IP 定位。
- **做行情/加密货币** → `CoinGecko`：免费额度对行情看板友好。
- **做知识/词典类** → `Wikipedia REST API`、`Dictionary API`、`Open Library`。
- **做科普/炫技页** → `NASA API`（每日天文图）、`Open Notify`（空间站实时位置）。

## 使用建议

1. 先用上方搜索框按关键词（如 `weather`、`github`）定位接口。
2. 点开链接去官网读文档，确认免费档的配额与 CORS 支持。
3. 需要密钥的接口，把 key 放在环境变量，通过后端代理调用。
4. 给接口加失败兜底（超时、限流），避免单点挂掉拖垮整个页面。
