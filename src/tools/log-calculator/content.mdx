## 对数计算原理

对数 log_a(b) 表示“a 的多少次方等于 b”。任意底数都可借自然对数换算：log_a(b) = ln(b) ÷ ln(a)（换底公式）。当 a=10 时为常用对数 lg，a=e 时为自然对数 ln。

## 这个工具能做什么

- 计算以任意实数 a 为底、b 为真数的对数
- 同时给出 ln(b) 与 lg(b)
- 支持常用对数、自然对数与自定义底数

## 怎么使用（输入说明）

1. 填写**底数 a**（如 10、2、2.718…）。
2. 填写**真数 b**（必须为正数）。
3. 下方即时显示 log_a(b)、ln(b)、lg(b)。

## 底数与真数的限制

必须满足：底数 a > 0 且 a ≠ 1，真数 b > 0。a=1 时对数无意义（1 的任何次方都是 1）；b ≤ 0 无法取对数。工具会自动拦截非法输入。

## 计算实例

例：log_10(1000) = 3（10 的 3 次方是 1000）
例：log_2(8) = 3；ln(1) = 0；lg(100) = 2

## 常见问题 FAQ

**Q：常用对数和自然对数有什么区别？**

A：常用对数以 10 为底（lg），自然对数以 e≈2.718 为底（ln）。本工具两者都给，底数可任意填。

**Q：ln(b) 和 log_a(b) 怎么互相换算？**

A：log_a(b) = ln(b) / ln(a)，这就是换底公式，工具内部正是用它在算。

**Q：真数能是 0 或负数吗？**

A：在实数范围内不能。ln(0)、log(-5) 均无定义，工具会提示错误。
