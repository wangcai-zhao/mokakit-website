## 为什么建议你「从零造一个 X」

读文档、调框架，很容易停在「会用」这一层。真正理解一个系统，最好的办法是**自己写一个能跑的玩具版本**。比如自己实现一个数据库，你会被迫搞懂 B 树索引、WAL、事务隔离——这些在你直接调 MongoDB 时永远藏在黑盒里。

这份清单按主题整理了 24 个经典练手项目，每个都指向一份社区教程。

## 怎么挑第一个

- **边界清晰、反馈快**：解释器、键值存储、Web 服务器——几小时就能跑通主路径，成就感强。
- **想啃硬的**：操作系统内核、区块链、Raft——周期长但收益深。
- **和主业相关**：做后端的从数据库/ORM 入手，做前端的从 Web 框架/模板引擎入手。

## 编辑精选路线

- **入门三件套**：编程语言解释器 → 文本编辑器 → 版本控制系统（理解「程序如何被运行与记录」）。
- **后端进阶**：数据库 → 键值存储 → 文本搜索引擎（一条存储主线）。
- **分布式启蒙**：Raft 一致性 → 负载均衡器 → DNS 服务器。
- **趣味向**：区块链、BitTorrent 客户端、OCR——拿来当博客素材很吸睛。

## 做的时候注意

1. 先跑通主路径，再补边界；不要一上来追求生产级。
2. 边写边画数据结构图，比闷头 coding 高效。
3. 写完后回看成熟开源实现，对比差距就是收获。
4. 把过程写成博客，比项目本身更值钱。
