## 为什么需要 XML 与 JSON 互转

老系统、银行接口、Office 文档、SOAP 还在用 XML；而现代前端、NoSQL、配置几乎全是 JSON。两边要打通，就得把 XML 和 JSON 互相转换。手工改既慢又容易把属性、文本节点弄丢。

本工具在 XML 与 JSON 之间双向转换：XML 转 JSON 时把属性收进 `@` 前缀、文本放进 `#text`；JSON 转 XML 时递归还原成标签结构。

## 概念与公式

XML 是带标签、属性、文本的树；JSON 是对象 / 数组 / 标量。两者并非一一对应，转换需约定映射：

- **XML → JSON**：元素名作键；属性以 `@属性名` 存放；元素文本放 `#text`；多个同名子元素收成数组。
- **JSON → XML**：对象键作标签；`@` 开头的值还原成属性；`#text` 还原成文本；数组展开成多个同名标签。

示例：

```xml
<user id="1"><name>张三</name></user>
```
→
```json
{ "user": { "@id": "1", "name": { "#text": "张三" } } }
```

## 细分场景

- **接口对接**：把 SOAP/XML 响应转 JSON 给前端用。
- **配置迁移**：老 XML 配置转 JSON 进新系统。
- **数据清洗**：统一格式后再做处理。

## 怎么用本工具

把 XML 或 JSON 贴入，选择方向（XML → JSON 或 JSON → XML），结果即时显示。解析失败会指出大致位置。复制即用。

## 常见场景与实例

**例：带属性的元素**
`<book id="b1"><title>深入浅出</title></book>` → 属性 `id` 进 `@id`，标题进 `title.#text`。
