## 为什么需要存储单位换算

「我的硬盘是 1 TB，怎么系统只显示 931 GB？」——这是几乎每个人都会遇到的困惑。根源在于存储行业用十进制（1 KB = 1000 B），而操作系统用二进制（1 KiB = 1024 B），两套口径混在一起，差出几个百分点。

本工具同时列出十进制（SI）与二进制（IEC）两套单位，输入一个数值即刻给出全部 12 种单位的等价值，再也不会被「标称容量」和「显示容量」搞晕。

## 概念与公式

存储的基本单位是字节（Byte，B），1 字节 = 8 比特（bit）。倍数分两套：

- **十进制（SI，硬标）**：K = 1000、M = 1,000,000、G = 10⁹、T = 10¹²、P = 10¹⁵。
- **二进制（IEC，系统用）**：Ki = 1024、Mi = 1024²、Gi = 1024³、Ti = 1024⁴、Pi = 1024⁵。

| 单位 | 符号 | 等于多少字节（B） |
| --- | --- | --- |
| 比特 | bit | 0.125 |
| 字节 | B | 1 |
| 千字节(SI) | KB | 1,000 |
| 二进制千字节 | KiB | 1,024 |
| 兆字节(SI) | MB | 1,000,000 |
| 二进制兆字节 | MiB | 1,048,576 |
| 吉字节(SI) | GB | 1,000,000,000 |
| 二进制吉字节 | GiB | 1,073,741,824 |
| 太字节(SI) | TB | 1,000,000,000,000 |
| 二进制太字节 | TiB | 1,099,511,627,776 |
| 拍字节(SI) | PB | 1,000,000,000,000,000 |
| 二进制拍字节 | PiB | 1,125,899,906,842,624 |

换算：目标 = 源值 ×（源单位字节数 ÷ 目标单位字节数）。

## 单位细分与对照

- **bit / B**：网络带宽常标 bit（如 100 Mbps），文件大小用 B，注意 8 倍关系。
- **KB / KiB**：标称与系统的第一道分歧，KiB 比 KB 大约 2.4%。
- **MB / MiB**：内存条、U 盘常用 MiB 口径。
- **GB / GiB**：硬盘/内存主流级，GiB 比 GB 大约 7.4%。
- **TB / TiB 及以上**：大容量存储，偏差累积更明显。

## 怎么用本工具

填入数值并选择当前单位（如「吉字节 GB」），页面即时列出全部 12 种单位结果，源单位标「输入」。点「复制」可取走任一结果。

## 常见场景与实例

**例 1：硬盘容量差异**
标称 1 TB = 1,000,000,000,000 B，系统在二进制下 = 1,000,000,000,000 ÷ 1,073,741,824 ≈ 931.3 GiB，所以「1 TB 显示 931 GB」。

**例 2：带宽与下载**
100 Mbps 宽带 = 100,000,000 bit/s = 12.5 MB/s（十进制）理论峰值；下 1 GB 文件约 80 秒（理想值）。

**例 3：内存条**
16 GB 内存条在二进制里常写作约 14.9 GiB，二者指同一物理容量，只是口径不同。
