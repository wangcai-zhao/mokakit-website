## 为什么签合同前该先算一笔印花税

很多人签完合同才想起来「好像还要交印花税」，一查才发现金额不小。印花税是就合同、产权转移书据等凭证按金额贴花（缴税）的税种，按次或按期申报。大额采购、租赁、借款合同的印花税积少成多，提前算清既能安排资金，也能避免漏报被催。

本工具按《印花税法》常见税目，选类型填金额就出应缴税额，还能勾选小规模纳税人减半优惠。

## 印花税税率长什么样

印花税按「万分之几」计，不是百分之几。常用税目：

| 税目 | 税率（按计税金额） |
|---|---|
| 买卖合同（购销） | 万分之三（0.03%） |
| 承揽 / 建设工程 / 运输 / 技术合同 | 万分之三（0.03%） |
| 借款合同 | 万分之零点五（0.005%） |
| 产权转移书据 | 万分之五（0.05%） |
| 租赁合同 / 保管 / 仓储 / 财产保险合同 | 千分之一（0.1%） |
| 营业账簿（资金） | 万分之二点五（0.025%） |

应纳税额 = 计税金额 × 税率。例如 100 万购销合同：1,000,000 × 0.03% = 300 元。

## 计税金额按什么填

- **分别记载**：合同同时写不含税金额和增值税的，一般按不含税金额计税。
- **未分开**：只写一个总额且含税的，可能按全额计税。
- **电子合同**：纸质的、电子的都算应税凭证，一样要交。

所以填「计税金额」时，最好填当地政策认可的那个基数，别一股脑填含税总额。

## 本工具怎么用

三步：

1. 选合同类型（自带对应税率），或填自定义税率覆盖。
2. 填计税金额（元）。
3. 若是小规模纳税人、小型微利企业或个体工商户，勾选「减半优惠」自动 ×50%。

结果区给出适用税率、应缴印花税；勾了减半还会列出未优惠应缴和减免额，方便对账。

## 哪些情况容易算错

- **把 0.03% 当成 3%**：差一百倍，大额合同尤其要盯紧单位。
- **忘了减半优惠**：政策期内小规等可减半，不勾就多交一倍。
- **电子合同漏报**：线上签的照样应税。
- **金额口径错**：含税、不含税、是否含价外费用，各地执行有细节差异。
