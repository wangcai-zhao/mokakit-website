## 系统提示词生成器的原理

系统提示词决定模型的「人设」与行为边界。把零散的想法拆成角色、目标、约束、语气、输出格式五个维度分别填写，再用固定模板拼装，比随手写一段更不容易漏掉关键约束，也方便反复迭代。

## 这个工具能做什么

- 把角色、任务、约束、语气、输出格式分别填好
- 一键生成可直接复制的系统提示词
- 中英文两套措辞，按需切换
- 输出可整段复制，粘贴进任意 AI 客户端

## 怎么使用（输入说明）

1. **填角色**：模型该以什么身份说话，例如「资深前端工程师」。
2. **填目标**：它要解决的核心任务是什么。
3. **填约束**：不许做什么、必须遵守什么规则。
4. **选语气与格式**：正式 / 口语 / 简洁，以及输出结构。
5. **生成复制**：点生成，整段复制进 AI 客户端即可。

## 常见问题 FAQ

**Q：生成的提示词能直接用吗？**

A：可以。输出是标准 System Prompt 文本，复制后粘贴进 ChatGPT、Claude、Kimi 等客户端的「自定义指令 / 系统提示词」框即可生效。

**Q：为什么还要手写约束？**

A：模板只保证结构完整，具体业务规则（如「只回答中文」「不编造数据」）仍需你补充，越具体模型越不容易跑偏。

**Q：会保存我的内容吗？**

A：不会。全部在浏览器本地拼装，不上传任何服务器。
