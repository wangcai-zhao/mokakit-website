## 四舍五入计算原理

四舍五入根据「保留位之后那一位」决定进位与否：0–4 舍去，5–9 进位。向上取整（ceil）不论小数多少都进到下一整数，向下取整（floor）直接舍去小数，银行家舍入（四舍六入五成双）在恰为 0.5 时向最近的偶数靠拢以减少累计误差。

## 这个工具能做什么

- 指定**保留小数位数**进行四舍五入
- 也可直接取整到十位、百位、千位
- 切换四种舍入方式：四舍五入 / 向上 / 向下 / 银行家

## 怎么使用（输入说明）

1. 填入原始数字。
2. 选舍入方式。
3. 选取整粒度：保留小数位 / 到十位 / 百位 / 千位。
4. 若选保留小数位，再填小数位数。

## 四种舍入方式

- **四舍五入**：最常用，看后一位 5 进位。
- **向上取整**：2.1 → 3，用于「至少需要多少份」。
- **向下取整**：2.9 → 2，用于「最多能装几箱」。
- **银行家舍入**：2.5→2、3.5→4，金融统计常用。

## 计算实例

例：3.14159 保留 2 位小数 → 3.14（第三位是 1，舍去）
保留 3 位 → 3.142（第四位是 5，进位）

例：到百位：1450 → 1500；到十位：1450 → 1450

## 常见问题 FAQ

**Q：四舍五入到指定位数怎么判断进位？**

A：看保留位之后那一位：0–4 舍去，5–9 进位。例如 3.14159 保留两位小数是 3.14。

**Q：向上取整和向下取整分别是什么？**

A：向上取整无论小数多少都进一（2.1→3）；向下取整直接舍去小数（2.9→2）。

**Q：「四舍六入五成双」是什么？**

A：银行家舍入法：舍去位为 5 且后面全 0 时向最近偶数靠拢（2.5→2、3.5→4），减少累计误差。
