## 三、连带修复清单（11 个文件）

### 3.1 补装 `@astrojs/check`——`npm run check` 此前一直不可用

**根因**：`package.json` 里有 `"check": "astro check"` 脚本，但从未安装 `@astrojs/check`。运行时会弹交互式确认框要求安装，在 CI/非交互环境下直接挂起（实测被 SIGTERM 杀掉）。

**修复**：安装 `@astrojs/check@0.9.10`，`npm run check` 现可正常执行。

> 这是**既有缺陷，非本次升级引入**（已用 `git show HEAD:package.json` 核实升级前也无此依赖）。但由于任务要求「运行 lint 与测试命令」，必须补齐才能真正执行类型检查。

### 3.2 修复 5 处`copyText(text)` 引用未定义变量（**真实运行时 bug**）

模式一致：`copy` 函数内调用了不存在的 `text`，正确的应是上方`useMemo` 计算出的结果变量。用户点击「复制」按钮会抛 `ReferenceError`。

| 文件 | 修正 |
|---|---|
| `src/tools/commit-gen/Tool.tsx` | `text` → `output` |
| `src/tools/currency-convert/Tool.tsx` | `text` → `result` |
| `src/tools/gitignore-gen/Tool.tsx` | `text` → `output` |
| `src/tools/license-gen/Tool.tsx` | `text` → `output` |
| `src/tools/mcp-config-generator/Tool.tsx` | `text` → `output` |

### 3.3 修复 XML 转义正则 typo（**安全隐患**）

`src/tools/xml-json/Tool.tsx:36`

```diff
- s.replace(/&/g, '&amp;').replace(/<//g, '&lt;')...
+ s.replace(/&/g, '&amp;').replace(/</g, '&lt;')...
```

原 `<//g` 是无效正则，导致 `<` **无法被转义为 `&lt;`**。JSON→XML 转换时若值中含 `<`，会产出非法 XML；若下游以浏览器解析则存在注入风险。

### 3.4 修复错误类型导入

`src/tools/_shared/dev-io.tsx:1` —— `ComponentChildren` 被从 `preact/hooks` 导入，实际它由 `preact` 导出。

```diff
- import { useState, useRef, type ComponentChildren } from 'preact/hooks';
+ import { useState, useRef } from 'preact/hooks';
+ import type { ComponentChildren } from 'preact';
```

### 3.5 `tsconfig.json` 排除 `workbench/`

`workbench/coolexplore-insert.ts` 整体是一个裸 `{ ... }` 数据块，被 `scripts/_insert-sites.mjs` 当作文本读取拼接进 `sites.ts`，**从设计上就不是合法 TS**（TS 5 同样报错）。该目录是数据暂存区（含 json/html），不应参与类型检查。

```diff
- "exclude": ["dist"]
+ "exclude": ["dist", "workbench"]
```

### 3.6 `astro.config.mjs` 补JSDoc 类型

`gptEnc` 的参数 `n` 隐式 any（`@ts-check` 下报错）。因该文件是纯 `.mjs`，**不能写 TS 注解**（试过会致 rolldown 解析失败），改用 JSDoc：

```diff
+ /** @param {string} n */
  const gptEnc = (n) => ...
```

## 五、遗留风险

### 🟡 中风险：64 个类型错误仍存（历史存量，非本次引入）

**重要澄清**：已通过对照实验证伪「TS 6 引入错误」的假设 —— 把TS 回退到 5.9.3 跑check，**同样是 73 errors**。这批错误是项目长期积累的（因为 `astro check` 从未真正跑通，一直被掩盖），与本次升级无关。

### 🟢 低风险：`@astrojs/sitemap` 成为事实上的未使用依赖

sitemap 已由 `scripts/gen-sitemap.mjs` 接管，但依赖仍在 package.json。是否移除需评估（保留成本极低，不影响构建），本次仅对齐版本，未动。
