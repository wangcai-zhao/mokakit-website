## 矩阵计算器怎么用

线性代数作业里最烦的不是理解概念，而是手算完不知道哪一步乘错了。这个工具把 2×2 和 3×3 的矩阵运算做成了网格：左边填矩阵 A，右边填矩阵 B，选一个运算，结果立刻以同样的网格显示。加减乘、转置、行列式、求逆、标量乘全都支持，遇到行列式为 0 的奇异矩阵会直接告诉你它不可逆，而不是甩一堆无效数字出来。所有计算本地跑完，断网也能用。

## 这个工具能做什么

- 矩阵加法与减法，逐元素运算
- 矩阵乘法，同时提供 A 乘 B 与 B 乘 A 两个方向
- 标量乘，用一个数去乘整个矩阵
- 矩阵转置，行列互换
- 行列式计算，并在结果区常驻显示 A 与 B 的行列式值
- 2×2 与 3×3 矩阵求逆，奇异矩阵明确报错
- 结果自动消除浮点噪声，去掉长长的小数尾巴

## 怎么使用（输入说明）

1. **矩阵规模**：先选 2×2 还是 3×3，切换时已填的数字会尽量保留。
2. **矩阵 A / 矩阵 B**：在网格里逐个填数，支持负数与小数，留空按 0 处理。
3. **标量 k**：做标量乘时填这个数，例如填 2 表示把 A 的每个元素都乘 2。
4. **选择运算**：点对应按钮切换，结果实时刷新。填了非数字内容会提示是哪一行哪一列有问题。

## 背后的原理/规则

矩阵加减法是逐元素运算，要求两个矩阵规模相同。矩阵乘法不同：乘积第 i 行第 j 列的元素由左矩阵第 i 行与右矩阵第 j 列逐项相乘再求和，正因为这种行列配对关系，换顺序后结果通常不一样，所以矩阵乘法不满足交换律。

行列式对 2×2 矩阵是主对角线乘积减副对角线乘积；对 3×3 矩阵按第一行展开成三个 2×2 行列式的代数和。行列式为 0 的矩阵叫奇异矩阵，行向量或列向量线性相关，没有逆矩阵。2×2 求逆有固定公式：主对角互换、副对角变号再除以行列式；3×3 求逆先算余子式矩阵，转置得伴随矩阵，再除以行列式。

## 计算实例

例一，A 为一行 1、2，二行 3、4，B 为单位矩阵。A 的行列式是 1 乘 4 减 2 乘 3，结果为负 2。A 的逆矩阵按公式得到一行负 2、1，二行 1.5、负 0.5，把它与 A 相乘应当还原成单位矩阵，可以用 A 乘 B 的方向验算一遍。

例二，若把 A 改成一行 1、2，二行 2、4，第二行是第一行的 2 倍，行列式为 0，点「A 的逆矩阵」会提示不可逆，这正是奇异矩阵。

## 常见问题 FAQ

**Q：什么情况下矩阵求不出逆矩阵？**

A：当矩阵的行列式等于 0 时它被称为奇异矩阵，此时没有逆矩阵，工具会明确提示不可逆。直观理解就是行向量或列向量线性相关，比如某一行是另一行的倍数，或者有一整行全是 0，二阶矩阵里只要两行成比例就会奇异。

**Q：结果里为什么会出现很长的小数尾巴？**

A：浮点运算天然有精度误差，二进制无法精确表示 0.1 这类十进制小数，直接相减可能得到一串极小的尾巴。工具在每一步运算后做六位小数归一化，展示时再收敛到四位小数并去掉末尾多余的 0，所以你看到的结果干净整齐。

**Q：矩阵乘法为什么不满足交换律？**

A：矩阵乘法要求左矩阵的列数等于右矩阵的行数，乘积的每个元素由左矩阵的行与右矩阵的列配对求和得到。换顺序后参与配对的行列关系变了，结果通常不同，所以 A 乘 B 与 B 乘 A 一般并不相等，工具因此把两个方向都单独列了出来。
