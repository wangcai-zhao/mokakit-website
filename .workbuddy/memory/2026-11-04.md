## 时区转换器并入（第 282 个工具，v0.10.1）

**背景判断**：站内原有时间工具各自只覆盖一角——`world-clock` 只看「此刻各地几点」、`timestamp-converter` 处理 Unix 数字与日期、`utc-to-pst/cst/est/edt` 是按固定偏移硬算的定点页（页面自述不考虑夏令时）。真正缺的是「A 地某个具体时刻 → B 地几点」，这次补上这一格。

**新增文件**：`src/lib/time-zone.ts`（算法层，零依赖只用 Intl，38 个城市/时区）+ `src/tools/timezone-converter/{meta.ts,Tool.tsx,content.mdx}` + `scripts/test-time-zone.mjs`（44 项断言）。

🔴 **依赖方向红线**：`src/lib/` 不允许 import `src/tools/`（含 `_shared/`）。故时区表在 lib 里单独一份，与 `_shared/timezones.ts`（带经纬度、供时钟栏目与世界时区地图定位）**并存但互不引用**，两份的职责分工写进了两个文件的头部注释。

**夏令时两个边界 = 这类工具的唯一真难点**，处理方式已定并写进测试：不存在的时刻（春季拨快）顺延并给出 `dstShiftMin`、页面提示；重复的时刻（秋季拨慢）取先发生的那次（与 Java / Python zoneinfo 的 fold=0 一致）。

**接入四处**：WidgetHost（import / `isTzConv` / known / load·idle·visible 三分支）、changelog 新增 2026.11.04 批次、site.ts 工具数 281→282（注释 + description 两处）、`src/lib/index.ts` barrel 加 `export * from './time-zone'`。

**验证**：`check:all` 七项全绿（widgets 282 / search 360 条 56.5KB / changelog 282 / version 0.10.1）；`astro check` 新文件 0 报错（存量 61，比基线 64 少）；build 677 页、sitemap 674 条；`grep -c astro-island` = 1，不是死壳。
