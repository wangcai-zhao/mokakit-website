## JSON 对比是什么

接口升级、配置变更、数据迁移时，需要知道两份 JSON 到底差在哪。逐字段递归比对比肉眼扫一遍靠谱得多。

## 这个工具能做什么

- 逐字段递归比对，标注新增 / 删除 / 修改
- 路径用 a.b[0].c 表示，可直接定位
- 可只看变化部分，统计各类数量
- 导出可读的差异清单

## 怎么使用（输入说明）

1. **左右两栏分别粘贴 JSON**
2. **按需勾选只看变化**
3. **看表格里的差异**
4. **复制差异清单**

## 使用时的几个注意点

- 数组按下标比对，插入元素会误报为修改
- 建议先格式化再比对，可读性更好
- 大 JSON 比对可能稍慢，属于正常现象

## 实例

版本号从 0.9.11 改成 0.9.12、tags 数组多了一项，工具会列出 1 处修改 + 1 处新增。

## 常见问题 FAQ

**Q：数组是怎么比对的？**

A：按下标一一比对。所以如果在数组中间插入一个元素，后面的元素会全部表现为「修改」。这种场景建议先排序再比。

**Q：路径里的 [0] 是什么意思？**

A：是数组下标。比如 tags[1] 表示 tags 数组的第二个元素，方便你直接定位到数据里的具体位置。

**Q：数据会上传吗？**

A：不会。比对逻辑完全跑在你的浏览器里，接口返回的真实数据、配置文件都可以放心贴进来比对。
