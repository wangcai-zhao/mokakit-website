## 时分秒转单位公式

把一段 时:分:秒 转成统一秒数，再换算到不同单位：

```
总秒数 = 小时 × 3600 + 分钟 × 60 + 秒
总分钟 = 总秒数 ÷ 60
总小时 = 总秒数 ÷ 3600
```

输入允许「超过 59」的分钟或秒（如 00:90:00），会先正确进位再换算。

## 这个工具能做什么

它把「HH:MM:SS 形式的一段时长」展开成总小时、总分钟、总秒三种口径，方便统计与报表：

- 工时汇总：把排班时长转成「总小时」用于计薪；
- 时长合计：把多段视频/任务时长并成总秒数；
- 数据清洗：把文本时长规范成数值单位。

## 怎么使用本工具

1. 在输入框填写 时:分:秒（如 01:30:00）。
2. 结果区列出总小时、总分钟、总秒数。
3. 支持小数与超过 59 的数值，无需先手动进位。

## 计算详解

先把 时:分:秒 合成总秒数，再做除法。例如 01:30:00：总秒 = 3600 + 1800 + 0 = 5400；总分钟 = 5400 ÷ 60 = 90；总小时 = 5400 ÷ 3600 = 1.5。非整小时会保留小数（90 分钟 = 1.5 小时）。若输入 00:90:00，会先识别为 1 小时 30 分再换算，结果一致。

## 计算实例

**例 1：01:30:00 是多少小时？**

总秒数 5400，总小时 = 1.5 小时，总分钟 = 90 分钟。

**例 2：02:00:00 呢？**

= 7200 秒 = 120 分钟 = 2 小时。

**例 3：00:45:30 是多少？**

总秒 = 2730；总分钟 = 45.5；总小时 = 0.7583（约 45 分 30 秒）。
