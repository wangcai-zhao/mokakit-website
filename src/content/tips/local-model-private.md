## 我遇到的具体问题

上个月 HR 丢给我一份离职补偿明细，里面 143 行，每行都有姓名、身份证号、手机号、补偿金额。她要我把金额按部门汇总、挑出超标的几行。问题是我们公司数据不能出内网，我平时顺手的云端大模型一条路直接堵死——把这份表粘到网页版对话框里，等于把全公司的人肉信息传了出去。我第一反应是"那我人工筛"，筛到第 40 行眼睛就花了，还把两行金额加串了。

## 为什么这事值得自动化

这种"含敏感字段、又得出结果"的活儿，财务和 HR 隔三差五就甩过来一次。手动做一份 143 行的表，光是逐行核对加求和就要 25 分钟往上，还容易看错行。更麻烦的是每次都心惊胆战——怕手滑把原始数据发到不该去的地方。算上精神内耗，一个月摊下来不少时间。

## 我是怎么用 WorkBuddy 做的

我把本地跑的 Ollama 通过 MCP 接进了 WorkBuddy，这样"理解数据"这一步完全在本地完成，原始数据不会出这台机器。mcp.json 里加一段：

```json
{
  "mcpServers": {
    "local-llm": {
      "command": "npx",
      "args": ["-y", "@moka/ollama-mcp@latest"],
      "env": { "OLLAMA_HOST": "http://127.0.0.1:11434" }
    }
  }
}
```

但我不直接把整张表丢给模型。先过一道本地预处理：用 [MokaKit 的 JSON 格式化工具](/tools/json-formatter/) 把每行只留"部门 / 是否超标标记 / 金额"三个字段，身份证和手机号这种直接砍掉；再用 [MokaKit 的 base64 编码工具](/tools/base64/) 给剩下的姓名做个本地占位编码，模型看到的是 `5b6p...` 而不是真名。最后才让本地模型做汇总。

## 中间卡在哪 & 怎么绕过去

第一个坑：配完兴冲冲发第一条消息，WorkBuddy 报 `MCP error: ECONNREFUSED 127.0.0.1:11434`。一查，Ollama 根本没在后台跑——我那台机器装了但没设开机自启，上次重启后服务是死的。手动 `ollama serve` 起来再试，连上了。

第二个坑更隐蔽：连上之后模型调用直接回 `model "qwen2.5" not found, try 'ollama pull qwen2.5' first`。我本地明明拉过模型，结果拉的是 `qwen2.5:7b` 这个带标签的全名，MCP 里只写了短名，对不上。用 `ollama list` 看真实名字改一致，才正常出结果。

第三个坑是脱敏那步的反效果：我一开始用 base64 编码身份证号想"看起来不像明文"，但 base64 是可逆的，懂行的人一解就还原。后来改成在本地预处理阶段直接丢弃敏感字段、只留汇总要用的数字，模型根本拿不到原始证件号，这才算真正不外传。

## 顺带的几个发现

其一，本地模型处理这种结构化汇总其实够用，而且对中文表格的理解不比云端差多少，换来的是数据零出网，这笔账很值。

其二，预处理那两步我后来固化成了固定动作：凡是要进模型的敏感 JSON，先用 [MokaKit 的 JSON 格式化工具](/tools/json-formatter/) 裁剪字段，再用 [MokaKit 的 base64 工具](/tools/base64/) 对必须保留的标识做本地编码。敏感字段能砍就砍，砍不掉的再编码，顺序不能反。

## 你也可以这样用

变体场景：你手上有客户名单、病历摘要这类不能外传的文本，想让 AI 帮你归类或提取，又不敢用网页版。同样的本地模型 + MCP 接法，前面加一道本地预处理就行。最小版本：一台装了 Ollama 的机器 + mcp.json 里那段配置 + 送模型前先过一遍字段裁剪。先保证"原始数据不出门"，再谈让 AI 干活。

## 常见问题

问：本地模型是不是比云端笨很多？ 答：看任务。表格汇总、字段提取这类结构化活儿差别不大；需要很强推理或长上下文的，本地小模型会露怯，那时候再权衡要不要走脱敏后上云。

问：base64 算加密吗，能拿来藏敏感信息？ 答：不算，base64 只是编码，可逆，谁都能解。真正不外传靠的是 preprocessing 阶段直接不把敏感字段送出去。

问：Ollama 一定要常开吗？ 答：要让 WorkBuddy 随时能调就得常开，嫌占内存可以按需 `ollama serve`，只是每次第一次调用前得先确认它在跑，不然就撞我那个 ECONNREFUSED。

问：公司没内网隔离，这套还有意义吗？ 答：有。哪怕只是不想把客户资料喂进第三方服务，本地跑模型 + 字段裁剪也能把泄露面压到最小。
