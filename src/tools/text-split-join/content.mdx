## 文本分割合并是什么

分割与合并是同一个操作的两个方向：split 用分隔符把字符串切成数组，join 用连接符把数组拼回字符串。

## 这个工具能做什么

- 七种内置分隔符 + 自定义（支持正则）
- 六种输出连接符
- 可同时去重、去空白、跳过空项
- 一键给每项加单引号，方便写 SQL

## 怎么使用（输入说明）

1. **粘贴文本**
2. **选输入分隔符与输出连接符**
3. **勾选去重、去空白等选项**
4. **复制结果**

## 使用时的几个注意点

- 自定义分隔符写正则时不用加斜杠，直接写 \s+ 就行
- 写 SQL 记得勾「加单引号」
- 中英文逗号要分清楚，别选错分隔符

## 实例

「张三，李四，王五」按中文逗号拆开，加单引号后用逗号连接，得到 '张三','李四','王五'。

## 常见问题 FAQ

**Q：自定义分隔符支持正则吗？**

A：支持。比如填 \s+ 表示按任意连续空白切分，填 [,，] 表示中英文逗号都算分隔符。

**Q：「加单引号」是干嘛用的？**

A：写 SQL 的 IN 条件时用：一组 ID 或姓名拆开后加上单引号再逗號连起来，直接粘进 WHERE name IN (...) 就能跑。

**Q：拆分和合并模式有什么区别？**

A：底层是同一套逻辑，只是侧重点不同：拆分模式关注「按什么切开」，合并模式关注「用什么连起来」。两个模式共用同一份输入和输出连接符设置。
