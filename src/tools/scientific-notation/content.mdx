## 科学计数法转换原理

科学计数法把一个数写成 **a × 10ⁿ**，其中 1 ≤ |a| < 10，n 为整数。工程计数法是其变体，要求指数 n 为 3 的倍数（…−6、−3、0、3、6…），系数放宽到 1–1000，便于与千、百万、十亿等单位对应。

## 这个工具能做什么

- 普通十进制数字 ↔ 科学计数法双向转换
- 同时给出**科学计数法**与**工程计数法**
- 支持直接输入 e 记数法（如 1.23e5）

## 怎么使用（输入说明）

1. 在输入框填入一个数字（普通小数或 1.23e5 形式均可）。
2. 结果区同时显示科学计数法、工程计数法与普通十进制三种表达。
3. 一键复制任意一种。

## 系数与指数

指数 n = floor(log10(|x|))，系数 a = x ÷ 10ⁿ。例如 123000：log10≈5.09，n=5，a=1.23，即 1.23×10⁵。工程计数法取 n 为 3 的倍数：n=3，a=123，即 123×10³。

## 计算实例

例：0.00045
科学计数法：4.5×10⁻⁴
工程计数法：450×10⁻⁶

例：602200000000000000000000（阿伏伽德罗常数近似）
科学计数法：6.022×10²³

## 常见问题 FAQ

**Q：科学计数法的标准格式是什么？**

A：写成 a×10ⁿ，1 ≤ |a| < 10，n 为整数。如 123000 = 1.23×10⁵。

**Q：科学计数法和工程计数法有什么不同？**

A：工程计数法指数必须是 3 的倍数，系数范围放宽到 1–1000，便于和千、百万等单位对应。

**Q：负指数代表什么？**

A：负指数表示很小的数，10⁻³=0.001，所以 5×10⁻³=0.005。
