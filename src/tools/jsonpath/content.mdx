## 为什么需要 JSONPath 查询

接口返回一大坨 JSON，你只想要 `data.list[0].user.name` 那一个字段；或者要从几百条记录里筛出所有 `status === "error"` 的项。手写循环遍历又长又烦，JSONPath 一行就能表达「查哪里、取什么」。

本工具用类 JSONPath 的语法在 JSON 上做查询/提取，支持点路径、数组下标、`*` 通配、`..` 递归下降、以及简单过滤，结果即时以 JSON 展示。

## 概念与公式

JSONPath 是 JSON 的查询语言，类比 XPath 之于 XML。常用语法：

- `$`：根节点。
- `.key` / `['key']`：取对象字段。
- `[n]`：取数组第 n 项（从 0 起）。
- `[*]`：数组全部元素。
- `..key`：从任意深度递归找名为 key 的字段。
- `..`：递归所有节点。

本工具在完整 JSONPath 之上，对最常用子集做了稳健支持：点路径、下标、`*`、`..` 递归、以及 `[?(...)]` 形式的简单等值/包含过滤（示例会在界面提示）。

## 细分场景

- **接口调试**：从大响应里精准取字段，不再肉眼翻。
- **数据提取**：批量捞某类节点做二次处理。
- **自动化脚本**：先在本工具试出路径，再写进代码。

## 怎么用本工具

左侧贴 JSON，上方填路径表达式，下方即时显示匹配结果（JSON 数组）。路径非法会给出提示。可多次改表达式实时对比。

## 常见场景与实例

**例：取嵌套字段**
`$.users[0].name` → 第一个用户的名字。

**例：递归找所有 id**
`$..id` → 文档里任意层级的 `id` 字段值集合。
