## UTC 转 PST 公式

太平洋标准时间（PST）为 UTC−8：

```
PST 时间 = UTC 时刻 − 8 小时
```

结果小于 00:00 退到前一天；超过 24:00 进入次日。工具标注跨天情况。

## 这个工具能做什么

PST 是美国太平洋时区（如洛杉矶、旧金山、西雅图）在 standard time 的时钟。本工具用于：

- 硅谷科技公司会议与发布时间换算；
- 美国西海岸赛事、直播排期；
- 跨境协作的时间对齐；
- 任何「UTC → 太平洋标准时」的需求。

注意：美国夏令时期间西海岸使用 PDT（UTC−7），非夏令时为 PST（UTC−8）。

## 怎么使用本工具

1. 填「UTC 小时（0-23）」与「UTC 分钟（0-59）」。
2. 结果区立即显示 PST 时间与跨天提示。
3. 可一键复制。

## 计算详解

总分钟 = (UTC时×60 + UTC分) − 480（8 小时），对 1440 取模得当日时刻，商为跨天数。例如 UTC 06:00 → 360 − 480 = −120 → mod 1440 = 1320 → 22:00，跨 −1 天即前一天。UTC 16:00 → 960 − 480 = 480 → 08:00 当天。北京（UTC+8）与 PST（UTC−8）相差 16 小时，北京早约 16 小时。

## 计算实例

**例 1：UTC 16:00 是太平洋时间几点？**

16 − 8 = 08:00，当天上午。

**例 2：UTC 06:00 呢？**

6 − 8 = −2 → 前一天 22:00（标注「前一天」）。

**例 3：UTC 00:00 呢？**

0 − 8 = −8 → 前一天 16:00。
