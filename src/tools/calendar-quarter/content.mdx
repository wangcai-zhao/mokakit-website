## 日历季度计算公式

按自然月划分季度，月份对 3 向上取整：

```
季度 Q = ceil(月份 ÷ 3)
起止月 = (Q − 1) × 3 + 1  ~  Q × 3
```

即 Q1=1~3 月，Q2=4~6 月，Q3=7~9 月，Q4=10~12 月。

## 这个工具能做什么

它把「某个月」映射到「第几个季度」，用于：

- 财年/季度规划：确认某月归属；
- 季度复盘：按 Q1-Q4 切分工作；
- 报表归类：把月度数据归入对应季度；
- 任何需要「月份 → 季度」的场景。

## 怎么使用本工具

1. 在「输入月份（1-12）」填写数字。
2. 结果区显示所属季度（如 Q3）与起止月份。
3. 可一键复制季度标签。

## 计算详解

季度是固定切分，不依赖具体年份。月份除以 3 向上取整即得季度序号；起止月由 (Q−1)×3+1 到 Q×3 确定。例如 8 月：ceil(8/3)=3 → Q3，起止 7~9 月。输入 1-12 之外会提示非法，不会误判。

## 计算实例

**例 1：8 月属于第几季度？**

ceil(8 ÷ 3) = 3 → Q3（7~9 月）。

**例 2：3 月呢？**

ceil(3 ÷ 3) = 1 → Q1（1~3 月），恰为季度末月。

**例 3：11 月呢？**

ceil(11 ÷ 3) = 4 → Q4（10~12 月）。
