## /go/ 中转页「链接不可用」bug 修复（旺财实测点开好站推荐报「跳转链接为空或格式不正确」）
- **根因**：`src/pages/go/index.astro` 原用 `Astro.url.searchParams.get('url')` 在**构建期（服务端预渲染）**读 query 参数。纯静态站构建时该页无 query，target 恒为空 → valid 恒 false → 「链接不可用」被**烤死在静态 HTML 里**，浏览器带 ?url= 进来仍读构建期空壳。
- **修法**：把校验逻辑改到**浏览器端**——静态外壳只放「正在校验链接…」占位，用 `<script is:inline define:vars={{siteHosts, nameCn}}>` 读 `window.location.search` 动态填充（valid 态显示目标域名+继续访问，invalid 态显示错误）。转义 safe/host 防 `?url=">` 注入。加 `<noscript>` 兜底。
- 校验：dist/go/index.html 含 `window.location.search`、`define:vars` 已注入 `siteHosts=["mokakit.com","mokakit.cn"]`/`nameCn="摩卡工具箱"`；node 模拟 5 用例（真实 URL / 空 / javascript: / 自己站）判定全对。构建 GREEN（192 页）。
- **可复用教训**：Astro SSG 下，「依赖运行时 query 参数」的页面绝不能靠 `Astro.url` 在 frontmatter 里读，必须客户端 JS 解析 `window.location.search`。
