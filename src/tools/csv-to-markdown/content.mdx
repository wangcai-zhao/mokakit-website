## 为什么需要 CSV 转 Markdown

写 README、记笔记、发技术文档时，经常要把一份 CSV 数据表变成 Markdown 表格贴进去。手工加 `|` 和分隔行又慢又容易错位，尤其列多的时候。

本工具把 CSV（含引号包裹、逗号内逗号、换行单元格）解析成标准 Markdown 表格，首行自动当表头，粘贴即出，复制即用。

## 概念与公式

CSV（逗号分隔值）是纯文本表格：每行一条记录，字段用逗号分隔；字段含逗号/换行/引号时用双引号包裹，内部引号写成两个引号 `""`。

Markdown 表格语法：

```
| 列1 | 列2 |
| --- | --- |
| a | b |
```

解析靠**状态机**逐字符扫描：遇到引号进入「引用模式」，直到下一个未转义引号结束；逗号切字段、换行切行。再按 `| 字段 |` 组装，并在首行下插入 `| --- |` 分隔行。

## 细分场景

- **文档 / 博客**：把导出数据直接变可读表格。
- **README**：项目对比表、参数表。
- **笔记整理**：从表格软件复制 CSV 贴进 Markdown 笔记。

## 怎么用本工具

把 CSV 贴入左侧，首行默认作为表头，右侧即时生成 Markdown 表格。支持带引号/换行的复杂单元格。点复制带走结果。

## 常见场景与实例

**例：带逗号的值**
```
name,note
张三,"方案 A, 待定"
```
→ 正确解析为两列，引号内逗号不被拆断。
