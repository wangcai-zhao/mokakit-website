## 智能体工作流生成器的原理

一个能跑的智能体，本质是一条有明确步骤的流程：哪步调模型、哪步调工具、哪步做条件判断。工作流生成器把「脑子里的大概流程」变成带类型的步骤清单与 JSON，降低从想法到落地的距离。

## 这个工具能做什么

- 步骤化定义模型 / 工具 / 分支
- 生成可读流程描述与 JSON
- 适配 n8n / Dify / LangGraph
- 方便团队评审与迭代

## 怎么使用（输入说明）

1. **加步骤**：每行一个节点，选类型写说明。
2. **排顺序**：按执行先后列出。
3. **生成**：得到流程描述与 JSON。
4. **落地**：复制进你的编排框架。

## 常见问题 FAQ

**Q：生成的 JSON 能直接运行吗？**

A：它是与框架无关的结构化描述，需映射到具体框架的节点格式；本工具给出的是清晰骨架，省去从零设计。

**Q：支持循环吗？**

A：当前以线性 + 条件分支为主，复杂循环建议在框架里再细化。

**Q：会上传吗？**

A：不会，本地生成。
