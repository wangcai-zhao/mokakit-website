## 比例计算原理

比例表示两个量之间的相对大小，记作 a : b。解比例利用「内项积 = 外项积」：若 a : b = c : x，则 a·x = b·c，移项得 x = b·c ÷ a。化简比则是把两边同除以最大公约数，得到最简整数比。

## 这个工具能做什么

- **解比例**：已知三项求出第四项未知量
- **化简比**：把 a : b 化为最简整数比并给出比值
- **按比例分配**：把总量按给定份数拆分到多份

## 怎么使用（输入说明）

1. 选择模式：解比例 / 化简比 / 按比例分配。
2. 解比例填 a、b、c，自动求 x。
3. 化简比填两个整数；分配填总量与各份数（逗号分隔）。

## 化简比与求比值

化简比得到最简整数形式（如 4:6 → 2:3）；求比值是前项除以后项的数值（4:6 的比值约 0.667）。两者互补：化简比看结构，比值看大小。

## 计算实例

例：解比例 2 : 3 = 4 : x
x = 3 × 4 ÷ 2 = 6，即 2:3 = 4:6

例：按 2:3:5 分配 100
总份数 = 10，每份 = 10
得 20、30、50

## 常见问题 FAQ

**Q：什么是解比例（交叉相乘）？**

A：已知 a:b = c:x，则 x = b×c÷a。原理是内项积等于外项积，移项即得。

**Q：化简比和求比值有什么不同？**

A：化简比得到最简整数比（保持比的形态）；求比值得到一个数值，用于比较大小。

**Q：按比例分配怎么用？**

A：输入总量和各份数，工具先求总份数，再用「总量 × 单份占比」算出每一份。
